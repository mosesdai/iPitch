## 术语速查（本页用到的）

| 说法 | 意思 |
|------|------|
| 证伪核查（有条件推进） | 专门找「我们哪里可能想错」的反方检查；结论=方向能谈，但先验证前提 |
| 禁用话术 | 这句话不许对客户说（说了会被打脸或冒犯） |
| 需当面问客户 | 公开渠道查不到，必须销售当面确认，材料里不装懂 |
| 主打矛盾点 | 客户官方说法与实际数据之间的矛盾，会面只打一个 |
| 来源 A / C | A=公司官方公告（最可信）；C=媒体/电商观察（仅供参考） |
| 不达标即停 | 先小规模试点，效果不到线随时叫停，财务好批 |
| 春节错位 | 春节时间移动导致 Q1 同比大涨/大跌，不等于经营反转 |
