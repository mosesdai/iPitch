### 2.3 关键经营层角色卡（营销相关）

#### 蒋建琪 —— 创始人 / 董事长 / 总经理

- **公开职责**：对公司经营结果负责；年报签字负责人。  
- **营销史接点**：2019 王俊凯升级发布会公开定义「年轻化」；长期被视为大广告时代操盘者（C 级商业故事）。  
- **2024–2025 信号**：收回总经理权；2025 营收/净利承压背景下仍推进多层代言+杭州店（行为可见，动机勿编）。  
- **Pitch 频道（假设，非事实）**：长期主义、渠道健康、品类升级——**须会面验证**。  
- **不可写**：已确认他是代言合同签字人 / EB。

#### 蒋晓莹 —— 董事兼品牌创新中心总经理

- **年报简历锚点**：2016 互联网创新中心 → 2019 互联网事业部 → **2022-03 品牌创新中心总经理**；2020-05 起任董事。  
- **公开成果接点**：虎啸奖相关通稿称其通过跨界/联名/圈层做创意营销；成都快闪有引语；多份通稿将其与双轮驱动、Meco/兰芳园创新绑定（B/C）。  
- **结构位置**：在公开组织叙事里，她是**最接近「品牌/内容/代言」日常操盘**的具名高管。  
- **仍禁止**：直接标注 Champion 或 EB。可写「**高优先级 L0 核实对象**」。

#### 邹勇坚 —— 董事 / 董秘 / 财务总监

- **公开职责**：财务与信息披露；销售费用同比下降的解释责任落在财务披露体系。  
- **与合作的逻辑接口**：广告费 0.79 亿 vs 市场推广费 2.57 亿（2025）——任何「体育/IP 试验」若要过预算，财务条线几乎必然入场。  
- **是否项目 Economic Buyer**：**【待核实】**（更可能是门槛/否决之一，而非创意 Champion）。

#### 杨静 —— 董事 / 副总经理 / 人资行政

- **公开职责**：人资行政中心；与门店试点的编制、外包店员（成都「男团」招聘等）可能相关。  
- **品牌代言决策**：**无公开证据** → 不抬权重。

#### 康琳 —— 会计机构负责人（年报财务报告签字人）

- **年报位置**：与蒋建琪、邹勇坚共同声明保证财务报告真实完整；即 **会计机构负责人（会计主管人员）**。  
- **注意**：部分第三方百科仍列其「监事」等历史职务；**以 2025 年报签字身份为准**；若公司已取消监事会，以其现职为准 **【建议下次年报/章程再核】**。  
- **营销决策权**：公开材料 **无**；勿写入购买路径。

#### 陆家华 —— 董事 / 实控人之一

- 持股与一致行动关键；**品牌创新公开出镜极少**。  
- 角色更像所有权层，而非 CMO 替代者。

## 4. MEDDIC（逐字段 · 置信度 · L0）

> 评分：高 / 中 / 低 / **无（禁止猜）**  
> 对象场景假设：若未来谈的是「场景/体育/IP/体验资产的可复用合作」——**非**已立项商机。

### M · Metrics（成功指标）

| 项 | 内容 |
|----|------|
| **已知（公开）** | 公司用营收/净利、冲泡 vs 即饮收入、Meco 果茶收入增速、销售费用与广告/推广结构、经销商数量与考核维度、Q4 降幅收窄等描述经营健康 |
| **与营销相关的可见指标** | 年报强调年轻化/健康化心智、内容闭环、线下反馈赋能研发；**未**披露代言 ROI、CPM、粉丝转化率等内部指标 |
| **置信度** | 公司级财务指标：**高**；营销项目级 KPI：**低 / 大部分无** |
| **L0【待核实】** | 孙颖莎/TNT 项目的成功定义是什么？经销商是否考核代言相关动销？杭州店 KPI 是体验人次还是饮品毛利？ |

### E · Economic Buyer（经济买方）

| 项 | 内容 |
|----|------|
| **已知** | 董事长兼总经理 **蒋建琪** 对经营结果负责；财务总监 **邹勇坚** 对费用披露与财务体系负责；实控人持股结构清晰 |
| **不可写** | 「EB = 蒋建琪」或「EB = 蒋晓莹」作为已确认事实 |
| **置信度** | 经营总责归属：**高**；**具体代言/体育试验的签批人与金额门槛：无（L0）** |
| **L0【待核实】** | ① 单笔代言 >X 万谁签？② 是否需董事会？③ 品牌创新中心是否有独立预算？④ 即饮与冲泡预算是否分池？ |

**结论句（强制）**：Economic Buyer = **【待核实】**。公开材料只支持画出「可能入场的职务集合」，不支持点名。

### D · Decision Criteria（决策标准）

| 项 | 内容 |
|----|------|
| **从公开行为反推的「可能标准」（标为推断，非客户原话）** | 人群匹配（年报写 Meco 选代言人考虑原点人群年龄与粉丝重合）；健康/年轻叙事一致性；产品创新可讲清；渠道库存与价盘健康优先于短期压货（年报渠道段） |
| **置信度** | 叙事一致性：**中**（有年报语言）；量化打分表：**无** |
| **L0【待核实】** | 供应商短名单标准；是否要求「可沉淀资产」而非纯曝光；体育 vs 娱乐的内部优先级 |

### D · Decision Process（决策流程）

| 项 | 内容 |
|----|------|
| **已知碎片** | 产品创新流程含品牌创新中心调研（年报）；经销商有开户审批与年度合同；重大人事走董事会；营销项目流程 **未披露** |
| **可见异常** | 快闪阶段对外称暂不开店 → 一年内杭州开店：说明流程上存在**策略修订**，但修订机制不透明 |
| **置信度** | 产品创新流程存在感：**中**；代言采购流程：**无** |
| **L0【待核实】** | 代理公司角色；法务/合规节点；蒋建琪介入的阶段（brief / final / 仅预算） |

### I · Identify Pain（痛点识别）

| 项 | 内容 |
|----|------|
| **有公开支撑的压力** | 2025 营收 29.26 亿（-11%）；冲泡受旺季窗口影响；礼品渠道价格战挤压经销商；销售费用仍高但广告降、推广升；现制茶饮分流杯装心智（行业常识，需会面确认其内部优先级） |
| **公司自称的应对** | 健康化（原叶现泡、古方五红等）、年轻化内容、即饮第二曲线、零食量贩/餐饮定制、线下体验试点 |
| **置信度** | 财务压力与自述战略：**高**；「哪一条痛到会买外部体育/IP OS」：**无** |
| **L0【待核实】** | 2026 预算里营销最大焦虑是老化、费用效率、还是经销商信心？ |

### C · Champion（内部冠军）

| 项 | 内容 |
|----|------|
| **可见高曝光候选人** | **蒋晓莹**（品牌创新中心 + 董事 + 奖项 + 快闪引语）在公开场最像「会推动新玩法」的人 |
| **纪律** | **不得**在未会面时标注 Champion=蒋晓莹 |
| **置信度** | 「公开品牌操盘高曝光」：**中高**；「愿为外部方案赌政治资本」：**无** |
| **L0【待核实】** | 谁会在内部会上为我们的方案辩护？是否存在隐藏 Champion（市场部总监、区域销售老总等未具名）？ |

**结论句（强制）**：Champion = **【待核实】**。

### P · Paper Process（流程/合规/纸面）

| 项 | 内容 |
|----|------|
| **已知** | 上市公司信息披露；经销合同年度制；关联交易制度（年报治理段）；代言/赞助合同细节 **未公开** |
| **置信度** | 上市合规意识：**高**；体育/娱乐合同模板与审批时长：**无** |
| **L0【待核实】** | 肖像排他、竞品条款、付款里程碑、是否走集中采购 |
