## 0. 生态位：三层替代同时发生

香飘飘的竞争不是「一个赛道打一家」，而是 **三层替代叠压**：

| 层 | 战场 | 对香飘飘的含义 | 代表对手 |
|----|------|----------------|----------|
| L1 场景替代 | 现制茶饮门店（即时、社交、冰饮） | 挤压冲泡礼赠/暖饮与即饮随手购的频次 | 蜜雪冰城、霸王茶姬、古茗等 |
| L2 货架替代 | 包装即饮茶/奶茶 | 与 Meco、兰芳园、即饮牛乳茶争冰柜与排面 | 统一阿萨姆、康师傅系即饮茶 |
| L3 同品类替代 | 杯装冲泡/固态饮料 | 争冲泡份额与礼品箱 | 优乐美（喜之郎系）等 |

公司自述品牌矩阵为 **「香飘飘 / Meco / 兰芳园」**，战略为 **冲泡 + 即饮双轮驱动**（A：2025 年报）。冲泡仍是基本盘但下滑；即饮（尤其 Meco）是第二曲线，绝对体量仍远小于现制巨头与即饮茶巨头——竞品分析必须以 **替代逻辑** 而非同规模对标展开。

**行业一句（A，香飘飘 2025 年报转引 NielsenIQ）**：2025 年饮料全渠道增速约 **0.2%**——包装饮料磨底；现制仍以门店与内容抢频次。二者周期不同步，是最大外部环境张力（详 05）。

## 1. 蜜雪冰城 / 蜜雪集团（02097.HK）——现制茶饮巨头

### 1.1 定位
极致性价比现制饮品；加盟扩张 + 供应链成本领先 + **自建「雪王」超级 IP**。2025 年报明确战略三角：**供应链 + 品牌 IP + 门店运营**（A：港交所 2025 年度业绩公告）。

### 1.2 关键公开数字（A）

| 指标 | 数值 | 来源 |
|------|------|------|
| 2025 收入 | RMB **335.60** 亿元，+35.2% | 蜜雪 2025 年度业绩公告 |
| 2025 年内利润 | RMB **59.27** 亿元，+33.1% | 同上 |
| 商品和设备销售 | 327.66 亿，+35.3% | 同上 |
| 加盟和相关服务 | 7.94 亿，+28.0% | 同上 |
| 2025 末全球门店 | **59,823**（内地 55,356 / 境外 4,467） | 同上 |
| 2024 收入对照 | 248.29 亿元 | 同上比较栏 |

### 1.3 对香飘飘的替代逻辑
1. **价格带重叠**：低价现制奶茶/果茶与冲泡礼盒、杯装果茶在「学生/下沉/随手一杯」场景互斥。  
2. **频次碾压**：现制可日频复购；冲泡旺季集中春节窗口（见 05），淡季被门店冰饮拿走。  
3. **心智代际**：雪王 IP + 洗脑主题曲 vs 香飘飘「绕地球」国民记忆——后者偏礼赠/怀旧，前者偏日常快乐。  
4. **体量**：蜜雪 2025 收入约为香飘飘全年营收的 **11 倍**（335.6 / 29.26，A÷A）。

### 1.4 近年公开动作（A）
- 持续扩店；2025 进入哈萨克斯坦、美国等市场。  
- **雪王 IP**：动画《雪王驾到》2025-05 多语种全球发行；与《西游记》、非遗唐三彩联名；截至 2025-12-31 抖音「#蜜雪冰城」话题播放量超 **653 亿**（A：中文业绩公告）。  
- 旗舰店：郑州东站等，「饮品+雪王文创」；截至 2025 末覆盖国内 **23** 城（A）。  
- 行业侧：第三方平台加大现制补贴，订单向线上迁移、性价比预期抬升（A：管理层讨论）。

### 1.5 香飘飘相对强弱

| 维度 | 香飘飘 | 蜜雪 |
|------|--------|------|
| 规模 | 2025 营收 29.26 亿（A） | 335.6 亿（A） |
| 场景 | 居家/礼赠/货架/差旅私享 | 即时门店社交 |
| 毛利结构 | 冲泡毛利率 43.80%，即饮 25.03%（A） | 加盟+商品设备模型，利润绝对额远高 |
| 护城河 | 杯装冲泡份额连续 14 年第一（公司自述，A）；Meco 杯装形态 | 门店密度 + 雪王 IP + 供应链 |
| 弱项 | 冲泡季节性、礼品价盘承压；即饮费用投放重 | 现制食品安全与加盟管控（行业共性） |

### 1.6 体育 / IP / 内容营销
- **主轴是自建 IP，而非体育赞助**。雪王 = 终身代言人 + 动画 + 巡游 + 旗舰店文创（A）。  
- 香飘飘对照：Meco 走 **顶流偶像代言 + 综艺冠名 + 动漫联名**（时代少年团、青春芒果夜、葫芦兄弟等，B/公司官网 + 年报「签约代言人」表述），属「借力流量」；与蜜雪「自有 IP 复利」不同。  
- **系统级职业体育赞助**：双方本稿均未检索到 A 源披露 → **【待核实 / 非主叙事】**。

## 2. 统一企业中国（00220.HK）· 阿萨姆奶茶——即饮茶/奶茶巨头

### 2.1 定位
传统包装饮料与方便面双轮；饮料内茶饮料、奶茶、果汁等大单品矩阵。**「统一阿萨姆奶茶」** 是即饮奶茶货架标杆，走高质平价、便利场景渗透。

### 2.2 关键公开数字（A：港交所 2025 末期业绩公告）

| 指标 | 数值 |
|------|------|
| 2025 集团收入 | 约 RMB **317.14** 亿元，+4.6%（B 与公告一致；以 A PDF 为准） |
| 2025 饮料业务 | RMB **194.71** 亿元，+1.2% |
| 茶饮料 | RMB **88.02** 亿元，+2.6% |
| **奶茶事业** | RMB **64.80** 亿元（约 6,479.7 百万），**+1.2%** |
| 果汁 | 约 33.40 亿元，约 -7.4%（B 对 A 解读） |

### 2.3 对香飘飘的替代逻辑
1. **即饮奶茶货架直接对撞**：阿萨姆 vs 香飘飘即饮牛乳茶及部分礼品装场景。  
2. **体量压制**：单「奶茶事业」一年约 **65 亿**，约为香飘飘全部即饮（2025：10.05 亿）的 **6+ 倍**。  
3. **增长同样钝化**：奶茶 +1.2% 与香飘飘即饮 +3.27% 同属存量微增——压力不止来自统一，更来自现制与无糖茶分流。

### 2.4 近年公开动作（A/B）
- 阿萨姆强调「产品力是王道」，拓展工作/家庭/休闲场景（A）。  
- 内容：独家冠名综艺《你好种地少年 3》等（A）。  
- 茶饮料侧：统一绿茶低糖/无糖双线、「统一双萃」柠檬茶（B）。  
- 低糖「茉莉奶绿」等延伸（C：媒体；新品规模 **【待核实】**）。

### 2.5 香飘飘相对强弱

| 维度 | 香飘飘相对统一 |
|------|----------------|
| 强 | 杯装果茶（Meco）形态差异化；冲泡礼赠心智；SKU 更「茶饮感」 |
| 弱 | 即饮奶茶绝对份额与铺市；经销体量；大单品历史广告资产 |
| 同弱 | 均受现制与无糖茶挤压；饮料板块低个位数增长 |

### 2.6 体育 / IP / 内容
以综艺冠名、场景营销为主（A）。**系统级体育赞助【待核实】**。偏「大单品长生命周期运营」，非 IP 人格化。

### 2.7 附：康师傅系即饮茶
同属货架即饮茶巨头，与统一、农夫构成即饮茶「前三」舆论格局（C：经济观察网等转引第三方）。康师傅 2025 分品类精确收入 **【待核实】**——本稿以统一为可核 A 源代表，康师傅作同层压力标注。

## 3. 优乐美（喜之郎集团）——冲泡 / 固态饮料直接对手

### 3.1 定位
杯装冲泡奶茶跟随者；背靠喜之郎果冻/海苔渠道与电视时代广告资产。历史叙事中曾与香飘飘「双雄」争夺（C：钛媒体等行业复盘；早期份额多为二手）。

### 3.2 关键公开数字
- **无独立上市公司分部披露** → 近年营收、份额、销量均为 **【待核实】**。  
- 行业旧口径常称香飘飘市占近 60%、优乐美第二（C：过时媒体）——**不可作 2025 现状铁数**。  
- 香飘飘 A 源可坐实：**2012–2025 连续 14 年杯装冲泡奶茶市场份额保持第一**（A：2025 年报）——隐含优乐美非第一，但**不给出对方精确份额**。

### 3.3 对香飘飘的替代逻辑
1. **同货架、同礼盒、同季节**：春节礼赠与商超冲调货架的零和。  
2. **现实替代强度可能下降**：多家 C 源描述优乐美商超可见度下降、创新保守——若属实，香飘飘冲泡下滑主因更可能是 **现制替代 + 礼品价盘 + 春节窗口错位**，而非优乐美抢量。  
3. **战略不对称**：香飘飘已上市并押注即饮第二曲线；优乐美公开进攻动作稀少（C）。

### 3.4 近年公开动作
可核的全国级产品/IP 战役：**检索未得 A/B 级系统披露 →【待核实】**。推断（标注推断）：防守型收割存量，资源优先果冻主业。

### 3.5 香飘飘相对强弱
- **相对优乐美**：份额与品牌第一心智、即饮转型、资本与 IR 透明度均占优（A + 逻辑）。  
- **不可自满**：第一名在萎缩赛道里「守第一」仍可能利润崩（2025 归母净利 -62.38%，A）。

### 3.6 体育 / IP / 内容
优乐美历史靠电视广告；近年内容营销公开动作 **【待核实】**。香飘飘冲泡侧已转向内容营销、快闪、IP 联名（A/B）。

## 4. 农夫山泉 · 东方树叶（9633.HK）——品牌年轻化 / 健康化标杆

### 4.1 定位
包装饮料龙头；**东方树叶** = 无糖茶长期主义标杆：慢培育、渠道密度、口味矩阵（六大茶类延伸），承接「减糖」消费共识。

### 4.2 关键公开数字（A：农夫山泉 2025 年报）

| 指标 | 数值 |
|------|------|
| 2025 集团收入 | RMB **525.53** 亿元，+22.5% |
| 2025 归母净利 | RMB **158.68** 亿元，+30.9% |
| **茶饮料收益** | RMB **215.96** 亿元，+29.0%，占总收益 **41.1%**（首次成第一大品类） |
| 包装饮用水 | RMB **187.09** 亿元，+17.3% |

### 4.3 对香飘飘的替代逻辑
1. **健康心智替代**：东方树叶「无糖茶」 vs Meco「果汁茶/轻负担」——都在抢「比奶茶更健康」叙事；东方树叶更贴近减糖政策语境。  
2. **货架与场景**：商超、便利、家庭大瓶（2025 春节 1.5L「大瓶茶，乐分享」，A）挤压含糖即饮与部分果茶。  
3. **方法论对照**：东方树叶证明「十年慢功夫」可换百亿级品类；Meco 走杯装差异化 + 偶像年轻化快攻——可学 **产品信念与渠道耐心**，非照搬无糖。

### 4.4 近年公开动作（A）
- 新口味：陈皮白茶、菊花普洱（2025-05）；春龙井/秋桂花乌龙季节款。  
- 营销：2025-04 首次「开盖赢奖」；大规格家庭场景。  
- 碳酸茶新品「冰茶」等延伸（年报表述）。

### 4.5 香飘飘相对强弱

| 维度 | 启示 |
|------|------|
| 可学 | 健康趋势前置；经销商共生与价盘；大单品长期主义 |
| 难抄 | 茶原料与渠道体量；无糖茶市占壁垒（C 称东方树叶无糖茶份额约 70–75%，**第三方，待复核**） |
| 差异化资本 | 杯装形态、果茶愉悦感、礼赠属性——与无糖茶不完全同质 |

### 4.6 体育 / IP / 内容
偏产品与活动营销，非卡通 IP 人格化；亦非体育赞助主导。区域体育合作 **【待核实】**。

## 10. 研究用观察（不进 pitch）

- 竞品「赢」的往往是 **可复利符号资产**（雪王）或 **十年级大单品**（东方树叶、阿萨姆），而非单次代言。  
- 2025 利润暴跌与 2026Q1 冲泡脉冲，说明慎用「拐点已成」——春节错位可解释脉冲，不可外推全年（见 05）。  
- 优乐美不宜再当「最大威胁」主轴，除非补到新的份额 A/B 源。
