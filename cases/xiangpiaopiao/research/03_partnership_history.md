## 1. 总判断（可进后续张力，不进 pitch 承诺）

1. **营销范式迁移有公开自述**：2025 年报写明「从传统广告模式向内容营销模式升级」，并给出费用结构佐证——**广告费下降、市场推广费上升**（见 §6）。  
2. **代言已明显「产品线分层」**：冲泡「原叶现泡」走**体育健康背书**（孙颖莎）；即饮 Meco 走**偶像年轻化**（时代少年团）；轻乳茶「名优」线走**跨代际甄选官**（侯佩岑）。是否同一套预算池、同一审批链 → **【待核实】**。  
3. **体验从「快闪造势」升级到「杭州常设试点店」**：年报明确承认杭州/成都快闪经验 → 2025Q4 杭州线下茶饮店；公司口径是品牌体验+研发反馈，非立即连锁扩张（媒体亦有「暂无加盟」表述）。  
4. **历史「一年卖出 X 亿杯 / 绕地球」是心智战遗产**：奠定国民品牌，但与当下健康化/年轻化叙事并存；旧心智如何被新代言「改写」而非「否定」→ 会面议题，非本文件结论。

## 4. 模式规律（研究用，非 pitch 断言）

### 4.1 代言演进：从「一个国民脸」到「多 SKU 多脸」

- **2015–2021**：主品牌换脸（钟汉良 → 陈伟霆 → 王俊凯 → 王一博），叙事关键词从销量国民感 → 有料/年轻 → 啵啵乳茶。  
- **2025**：同一集团内 **至少三套公开人格资产**并行——孙颖莎（健康/运动）、时代少年团（Z 世代情绪）、侯佩岑（名优/文化）。  
- **风险（待证）**：经销商 1,703 家如何同步三套物料与话术；渠道是否只认「香飘飘」大牌子而不认子线。

### 4.2 体育：有接口，未见「赞助体系」

- 唯一高强度体育接口是 **孙颖莎代言（E13）**。  
- 公开检索未见香飘飘作为乒乓球赛事冠名方、俱乐部赞助商的 **A/B 级材料** → 写「体育营销战略」会过度解读；更稳表述是 **「运动明星为健康化背书」**。

### 4.3 体验：快闪验证 → 杭州试点

年报原文逻辑链清晰：**快闪实践 → Q4 杭州店 → 品牌窗口 + 研发反馈**。  
「不开店」→「开店」之间的内部争论与 KPI **【待核实】**——这是权力/MEDDIC 的 Decision Process 缺口，见 `06_power_meddic.md`。

### 4.4 IP / 综艺：点状高，体系未知

- 动漫：葫芦兄弟（可核验 C）+ 年报「热门动漫 IP」泛指。  
- 综艺：芒果青春夜（C）+ 《乘风2025》人物接口（C，人物名需核实）。  
- **缺失**：是否有年度 IP 框架合同、代理公司名单、排他条款 —— 全部 **【待核实】**。
