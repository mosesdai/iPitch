# PRIMARY_REQUIRED · 赞意广告

| 字段 | 值 |
|------|-----|
| tier | B（代理商 · 无 IR） |
| 状态 | **open** |
| 阻塞 | 体育预算有无 · 签单主体 · Economic Buyer · 12 个月体育交付事实 |

## 为何需要 L0

外部 L2 能证明：4A 身份、年轻化作品密度、「确定性」叙事、赞意体育挂牌与负责人履历。  
**无法从公开页读到**：体育是否有单列预算、谁一票否决、现任客户是否要体育、厂牌是否已空转。

## 待验证假说

**假说**：赞意愿意把体育试验嵌进其胜率系统（可复盘、可熔断），并存在可批准试点的决策人。  
**若真**：谈 90 天试点定义 + 签单路径。  
**若假**：discard 体育主刀；改品效/AI 工作流，或结束。

## 销售 checklist（首面后 72h）

- [ ] 客户 business problem 原话（他们自己的词）
- [ ] 见面人：乌东伟线 / 柴文进线 / 客户总监 / 其他
- [ ] 体育合作：initiator / champion / veto
- [ ] 主合同拟落法人主体
- [ ] 过去 12 个月体育相关立项数量（可匿名）
- [ ] 体育预算：单列 / 挤占品效 / 无
- [ ] #1 顾虑：不确定归因 / 内部抢功 / 品牌主直采 / 编制不够
- [ ] 是否接受 90 天熔断试点

## 会面三问

1. 「体育提案，和品效提案，过不算过的标准是不是同一张胜率表？」  
2. 「过去一年，体育相关真正立过项的有几单？主合同签在哪个主体？」  
3. 「若只做一个 90 天可复盘小试验，谁有权批、谁有权停？」  

## 明确不说（直到 L0 closed）

- 具体赞助金额 / 权益包报价
- 「你们体育不行 / 没能力」
- 亲爱男友销售额当代理财力
- 未核实的现任客户名单敲定
- 我方粉丝量或品牌排场开场
