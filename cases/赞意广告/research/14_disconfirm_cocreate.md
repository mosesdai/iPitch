# 14｜联合销售与反证：先证明值得合作

## 1. 本篇目的

联合销售容易被“资源互补”四个字推动，却在客户归属、成本、数据、案例权和风险上失败。本篇把合作当成待证明假说：先找到足以否定合作的事实，再决定是否投入提案和交付资源。

## 2. 合作假说

外部体育资产或运营能力，可能帮助赞意体育补充资产供给与履约；赞意可能提供客户理解、创意、品效和社群链路。公开资料只能支持“存在互补可能”，不能证明双方已有共同客户、预算、签约意愿或组织授权。

## 3. 必须同时满足的条件

1. 有真实客户问题，而非仅为新厂牌制造新闻。
2. 至少存在可确认的试验预算或资源投入。
3. 双方知道谁拥有客户关系、谁签合同、谁收款。
4. 资产、活化、数据和复盘均有明确负责人。
5. 接受预先约定的停止、替换与退出条件。
6. 项目后双方都能获得合法、可复用的学习。

## 4. 红灯与动作

| 红灯 | 为什么危险 | 建议动作 |
|---|---|---|
| 只要资源清单，不给目标 | 无法判断适配 | 暂停定制 |
| 只谈曝光，不谈承接 | 难形成业务价值 | 要求补路径 |
| 合同主体不清 | 回款与责任风险 | 不报价 |
| 拒绝披露第三方成本规则 | 容易争议 | 先确认商业条款 |
| 不允许熔断 | 风险不可控 | 不进入执行 |
| 把负责人履历当案例 | 证据错位 | 要项目台账 |
| 用亲爱男友GMV证明预算 | 主体与口径错误 | 立即纠偏 |
| 外部方只能临时出力、无学习与案例权 | 关系不可持续 | 重新谈边界 |

## 5. 三个反证试验

**试验一：最近项目回放。** 请赞意用一个真实项目走完需求、预算、采购、执行、数据和复盘。若接口无法说清，先不谈规模合作。

**试验二：资产桌面评审。** 双方用同一评分表评三个不同大小的体育资产。若最终仍只靠名气或个人偏好决定，说明产品化尚未成立。

**试验三：最坏情境演练。** 假设赛事改期、运动员缺席或品牌临时缩预算，测试谁决定、多久响应、成本谁承担。若没有答案，先补合同机制。

## 6. 继续、修改、停止

- **继续**：真实客户、预算、owner、合同与数据路径全部闭环。
- **修改**：客户问题真实，但资产或交易结构不合适；缩小试验。
- **停止**：合作只服务公关叙事，或任何一方拒绝风险、成本与数据透明。

## 7. 联合销售的责任边界

谁约客户、谁主持、谁写方案、谁报价、谁承诺交付、谁承担差旅与定制成本、未中标方案归谁，都应在进入客户会议前书面确认。否则“联合”往往意味着一方提供关系，另一方无偿投入。

## 8. 当前裁决

公开证据支持继续做低成本验证，不支持直接承诺规模化联合销售。赞意体育的真实项目台账、预算、签约主体、客户需求和内部RACI均【待核实】。在这些缺口关闭前，所有合作设计都保持条件式。

> 研究截止：2026-08-28。本篇只使用公开可追溯材料与用户简报。公司稿、认证主页和项目复盘按其原始口径保留；没有来源的组织权、预算、收入、客户续约和效果一律写【待核实】。
>
> 口径红线：亲爱男友的累计销售额是被孵化品牌的交易规模口径，不是北京赞意互动的代理营收，更不是利润。人物履历不等于赞意主体案例；“合作过”不等于当前仍为客户。
