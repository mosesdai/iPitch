# PRIMARY_REQUIRED · 赞意广告

| 字段 | 当前值 |
|---|---|
| 状态 | **open** |
| 证伪结论 | **CONDITIONAL（有条件推进）** |
| L0 含义 | 来自当事人的一手回答、材料或项目记录 |
| 当前阻塞 | 会面人、合作模式、真实优先级、完整体育项目链、预算与决策人均未确认 |

## 为什么必须拿 L0

公开资料能证明赞意强调系统化增长、已成立赞意体育、拥有多个业务单元；却不能证明体育业务当前优先级、内部交付链、预算、合同关系和谁能拍板。

最危险的误判是把“公开没看到”说成“对方没有”。首面要让对方纠正我们，而不是拿外部资料给对方下结论。

## 待验证假说

**假说**：赞意体育真正值得共建的，不是再增加一个资源清单，而是把体育项目变成可验收、可复盘、可复制的增长交付。

**若真**
- 选一个真实客户问题，而非泛谈体育营销。
- 明确赞意、资产方/合作方、品牌主各自责任。
- 共同定义过程、结果口径、风险和停止条件。

**若假**
- 若内部已经闭环：承认判断错误，转为补充特定资产、线索或产能。
- 若体育不是当前优先级：停止体育主线，转向对方主动提出的业务。
- 若没有项目窗口、负责人或预算：不做方案，只保留关系维护。

## 会面恰 3 问

1. **“在你们最近一个体育项目里，从客户问题、资产选择到执行和复盘，最难标准化的是哪一段？”**
2. **“未来两个季度，赞意体育是主动扩张、机会型承接，还是暂不投入？”**
3. **“如果共同验证一个项目，谁对业务结果负责、谁能决定预算、什么结果会让你们继续或停止？”**

## 首面后 72 小时 checklist

### 业务事实
- [ ] 记录客户用原话描述的第一业务问题，不自行改写成“缺体育”。
- [ ] 记录一个真实项目或明确的下一项目窗口；没有则标“无项目”。
- [ ] 记录体育业务当前优先级：主动扩张 / 机会型承接 / 暂不投入。
- [ ] 记录最难环节：资产、线索、策略、执行产能、跨单元协同、数据复盘或其他。

### 人与决策
- [ ] 核对会面人真实职责及其在该项目中的角色。
- [ ] 写清发起人、业务负责人、预算决定者、合同签署方和否决方；未知继续标空。
- [ ] 判断对方是信息提供者、内部推动者，还是最终决定者，不因头衔猜测。
- [ ] 确认合作关系：赞意总包、联合提案、品牌主直签或共同孵化。

### 钱与流程
- [ ] 确认是否存在预算池；不强求敏感绝对数，但记录预算归属。
- [ ] 区分资产费、服务费、媒介/制作费及第三方成本。
- [ ] 记录采购、法务、数据安全、版权、排他和付款的必要节点。
- [ ] 记录最近可行动日期和下一步所需材料。

### 交付与证据
- [ ] 拿到一个项目的责任链：客户问题—方案—执行—结果—复盘。
- [ ] 记录指标原话、数据来源、基线、验收人和停止条件。
- [ ] 核对谁拥有数据、内容、案例发布权和可复用资产。
- [ ] 若对方声称体系已成熟，索取可分享的模板、匿名样例或客户确认；拿不到不等于不存在。

### 72 小时裁决
- [ ] **继续**：真实问题、项目窗口、责任人三项齐全。
- [ ] **改向**：只缺单项资源，转为具体资源/产能合作。
- [ ] **停止方案化**：无优先级、无项目、无负责人；只做关系跟进。
- [ ] 更新 `ifalsify_report.md`，记录哪条 F 被证实或被推翻。

## 明确不说

- 不说“赞意体育能力薄/没有闭环”。
- 不说“体育是赞意 2026 第一战略重点”。
- 不说“我们能保证确定性增长/保证销量”。
- 不把柴文进、乌东伟或任何公开头衔直接等同于项目拍板权。
- 不把加入中国 4A 当作项目交付成熟的证明。
- 不把亲爱男友累计销售额当赞意营收、利润或代理业务成绩。
- 不报赞意精确人数、营收、利润、客户份额和预算。
- 不展示未经确认的权益包、赞助金额、排他关系和客户名单。
- 不因公开资料缺少案例，就断言内部没有案例。
