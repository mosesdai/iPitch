# 赞意广告 disruptive - 跳出盒子：两种新品类，不是两个 Campaign

## 判定标准

赞意 2026 叙事是「从广告公司毕业，做确定性增长伙伴」。跳出盒子概念必须改的是**合作品类与验收单位**，不是再做一个年轻 KV。

| | A · 体育胜率闸门 Sports Certainty Gate | B · 品牌主体育路由台 Client Sports Router |
|---|---|---|
| 旧品类 | 体育营销策划/赞助方案书 | 按单品牌做一次赛事 Campaign |
| 新品类 | 把体育立项装进「胜率系统」的闸门产品 | 代理把多品牌客户路由到可复盘体育试验的台面 |
| Job | 让体育提案与品效提案过同一张过线表 | 让客户总监用一套字段分发试验，而不是每次重写故事 |
| 主受益者 | 赞意体育 + 合伙人层 | 赞意客户总监 + 品牌主增长负责人 |
| Why now | 2024-09 厂牌新开 × 2026 确定性叙事 | 公开客户池含快消/平台，体育需求分散 |
| 验收 | 闸门字段采用率、熔断触发、90 天复盘闭环 | 路由单数、客户复用、试点停机权清晰度 |

## 为什么两个

- A 是**对内操作系统**：解决「体育进不进胜率表」。
- B 是**对外产品界面**：解决「品牌主怎么买到可停的试验，而不是又一次热闹」。
- 可单独试点；若同时采用，B 的每一单必须先过 A 的闸门。

## 不做

- 不说赞意「不会做年轻化」；
- 不承诺未核实 ROI；
- 不把亲爱男友 GMV 当预算证明；
- 不替代赞意现有品效产品；
- 不假设品牌主会分享私域全量数据。

## 建议会面使用

先用 A 对齐合伙人/柴文进线「系统是否接纳体育」；若认，再展 B 作为可卖给品牌主的产品形状。若体育无预算，B 也可降级为品效路由台（PIVOT）。
