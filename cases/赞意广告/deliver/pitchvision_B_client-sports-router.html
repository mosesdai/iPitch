Job Map · 品牌主体育路由台

When

  • 多品牌客户并行；
  • 客户要确定性而非「可能爆」；
  • 体育/娱乐资源需要产品化出口；
  • 客户总监时间被重复提案吃掉。

Want

“像派工单一样派体育试验：问题清楚、模板清楚、停得下来、学得走。”

But

现在妥协
每个客户从头创意不可比、不可复用
爆款逻辑与确定性叙事冲突
资源靠人脉临时找无法产品化

Struggling moment

“这个月三个客户都问体育/年轻，我们写了三份互不相关的方案——没有一张能告诉我哪类问题该配哪类试验。”

New Job

Route brand problems to stoppable sports trials via a shared router.

Hire / Fire

  • Hire：路由台、模板库、字段教练
  • Fire：一次性宇宙级提案、无停机的大赞助冲动

Vision Card · 品牌主体育路由台 Client Sports Router

Vision Card · 品牌主体育路由台 Client Sports Router

一句话

不是替一个品牌再打一场赛事 Campaign，而是给赞意的客户总监一张可分发、可停机、可复用的体育试验路由台。

旧品类 → 新品类

旧：单品牌赛事 Campaign
每个客户从零讲故事、选明星/赛事、做 KV，结束即散。

新：Client Sports Router（品牌主体育路由台）
把「哪类客户问题 → 哪类体育试验模板 → 哪类验收字段」做成台面；客户总监像路由单一样派单，而不是每次发明宇宙。

Job

当赞意服务多品牌（快消/平台/汽车等公开客户池）且客户要确定性时，客户总监想要：

用同一套试验语言服务不同品牌：选问题、选模板、选停机条件；留下可比较的学习，而不是本季最火的那支片。

Why now

  • 公开案例覆盖多品类，说明客户入口多、问题异质；
  • 公司推产品化 / 六大产品叙事（公开稿）；
  • 体育厂牌需要「可卖给品牌主」的形状，否则只剩对内故事；
  • 品牌主越来越拒「可能会火」的溢价（赞意己方原话方向）。

产品构件

  1. Problem Cards：增长问题卡片（上市、年轻化心智、渠道动员、信任证明…）；
  2. Trial Templates：90 天试验模板（内容节点 / 小场次 / 权益小模块）；
  3. Router Sheet：客户 → 问题 → 模板 → 指标 → 停机；
  4. Learning Log：跨客户可沉淀的「什么试验有效」（脱敏）；
  5. Co-sell Slot：外部权益方按模板接口接入，不按人情插入。

改变的单位

旧单位：一支 Campaign。
新单位：一张路由单（可复制到下一个客户）。

三个现场画面

  1. 客户总监早会：三张路由单并行，而不是三个互不相关的头脑风暴。
  2. 品牌主会：先选 Problem Card，再谈资产。
  3. 复盘会：比较两张路由单的字段完成度，而不是只比播放量。

最小试点

  • 1 名客户总监 + 2 个愿意试点的品牌问题（可匿名）；
  • 只用模板桌面走单，不强制买大权益；
  • 产出：2 张完整路由单 + 1 次停机演练。

可验收

  • 路由单从构想到评审的周期；
  • 字段完整率；
  • 客户是否愿意第二单复用模板；
  • 是否出现「无停机权就不立项」。

90 天

与 A 闸门绑定：无 A 则 B 只做品效路由 PIVOT；有 A 则体育模板上架。

反证

若赞意商业模式拒绝产品化、坚持按天才做单 → B KILL。
