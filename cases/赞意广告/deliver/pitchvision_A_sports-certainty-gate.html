Job Map · 体育胜率闸门

When

  • 公司对外讲确定性增长；
  • 体育厂牌新开，需要证明不是空挂；
  • 品效/创意已有成熟评审习惯；
  • 外部合作方想进场。

Want

合伙人 / 赞意体育想：

“体育可以做，但必须像品效一样能说清：过线标准、谁停机、90 天留下什么。”

But

现在 hire 的方案实际妥协
更大创意体育方案热闹，难进财务语言
只讲负责人履历人强 ≠ 系统在
先签大资产再想复盘沉没成本绑架
体育独立评分与「一个系统」叙事分裂

Struggling moment

“对外讲确定性；对内体育提案仍按感觉过会——客户问胜率时，我们只能改口讲年轻。”

（外部假说，首面验证）

New Job

Install a certainty gate for sports：让体育立项先过系统，再进创意。

Functional jobs

  1. 字段可填；2. 与品效可比；3. 可退回；4. 可停机；5. 可复盘；6. 外部模块可插拔。

Emotional jobs

  • 合伙人不再害怕体育拖累确定性叙事；
  • 体育团队不再觉得被系统歧视，而是被系统收编；
  • 外部合作方知道怎么被评估。

Hire / Fire

  • Hire：闸门产品、字段教练、试点设计
  • Fire：无熔断的大方案、纯履历背书、绕过评审的「特批创意」

Vision Card · 体育胜率闸门 Sports Certainty Gate

Vision Card · 体育胜率闸门 Sports Certainty Gate

一句话

不是再给赞意体育加一场年轻玩法，而是给每一单体育立项装上一道与品效共用的过线 / 停机闸门。

旧品类 → 新品类

旧：体育营销方案书
讲资产多大、多年轻、多破圈；赛季末用曝光与情绪复盘。

新：Sports Certainty Gate（体育胜率闸门）
立项前必须填：胜率字段、签单主体、90 天指标、熔断权、品牌 Job；过不了闸门就不进入创意制作。

Job

当赞意要把「确定性增长」做成公司故事、同时又新开体育厂牌时，合伙人与体育负责人想要：

体育不再是例外特区——它要么进同一张胜率表，要么明确标成实验预算；CFO/客户总监看到的是可停机的试验，不是又一份热闹 PPT。

Why now

  • 2024-09-26 官宣赞意体育与一站式主张（公开）；
  • 2026 公司主叙事转向确定性 / 胜率 / 产品化（公开）；
  • 体育天然高不确定，与主叙事存在张力（推断，须会面验证）；
  • 公开交付清单仍薄 → 更需要闸门，而不是更大声的宣言。

产品构件

  1. Gate Form：过线字段（问题、资产、Job、指标、停机条件、主体）；
  2. Same Scorecard：与品效提案共用的胜率维度（可配置权重）；
  3. Kill Switch：未达门槛 / 无签单主体 / 无复盘权 → 自动不进入制作；
  4. Proof Stub：90 天只允诺「字段闭环 + 一次复盘」，不允诺销量神话；
  5. Partner Slot：外部权益/中台只能作为闸门内的可替换模块，不能绕过闸门。

它改变的不是传播物，而是立项单位

旧单位：一份创意方案。
新单位：一次过闸试验：

问题 → Job → 资产模块 → 指标 → 停机权 → 签单主体 → 复盘

若交付仍是「更酷的体育 KV」，它就不是新品类。

三个现场画面

  1. 内部评审： 体育提案与抖音品效提案排在同一队列，缺熔断字段的直接退回。
  2. 与权益方对齐： 先问「你们能否填进闸门字段」，再谈报价。
  3. 客户首面： 不展示资产清单，先展示一张空白闸门表，请对方改字段。

首个最小试点

  • 不接真实大额赞助；
  • 选 1 个内部假想品牌或 1 个愿意匿名的历史客户；
  • 跑 2 次桌面演练：一次过闸、一次被熔断；
  • 输出：字段字典 + 谁有权停机。

可验收指标

  • 体育立项使用闸门比例；
  • 因缺字段被退回次数；
  • 90 天内完成复盘的比例；
  • 合伙人是否认可「与品效同一表」（会面确认）。

目标值不预填。

90 天验证路径

  • 0–30： 对齐是否存在体育预算与决策人；若无，KILL/PIVOT。
  • 31–60： 只做字段与桌面演练，不买权益。
  • 61–90： 若 L0 关闭，跑一个真实小试验的闸门闭环。

反证（必须保留）

若赞意坚持体育是品牌故事特区、拒绝同一胜率表 → 本概念 KILL，改谈品效/AI。
