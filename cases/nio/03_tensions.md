## T1 · 三品牌分层 vs 一套体育叙事打三线【主刀】

| 侧 | 内容 |
|----|------|
| **主张** | 三种 Spirit：敢想有为 / 轻松家庭 / 自在发光；处于「品牌澄清期」（C13） |
| **行为** | **2026-06**：蔚来 **21,908**（自算 +9.5%）· 乐道 **11,743**（自算 **−2.4%**）· 萤火虫 **6,946**（自算 **+22.7%**）（C06 · A）；5 月乐道 **12,029**（C05 · A） |
| **和谐？** | **否** —— 三条线同月往 **三个方向** 走；一套素材不可能同时服务 |
| **后果** | 一套体育叙事打三品牌 → 乐道觉得「太燃太远」、蔚来觉得「被稀释」、萤火虫拿不到自己的语言 |
| **出口** | **一套 OS 三个接口**：蔚来 = 精神层（姚明桥延伸）· 乐道 = 家庭社群（申花模板换项目）· 萤火虫 = 青年文化（当前全空） |
| **会面一句** | 「六月三条线是 21,908、11,743、6,946——**方向都不一样**。这时候一套体育叙事该怎么分？」 |
| **L0 待验证** | 三品牌 KPI / 预算是否分家（PRIMARY Q1）；反证 F-1 |

**T1 的升级点（v3 → v1.6）**：v3 用的是「乐道 5 月破万 = urgency 上升」。v1.6 改用 **「破万的峰值没有变成台阶」**（12,029 → 11,743）。
后者更强，因为：① 全盘同月在涨（37,705 → 40,597），第二品牌单独在落，对照极干净；② 不需要对方承认任何痛点；③ 完全不依赖媒体叙事。

## 四条张力的相互关系

```
T4（费用闸门） 决定「形态」：必须小额可停
        ↓
T1（三品牌分化） 决定「结构」：必须分层，任一层单独成立   ← 主刀
        ↓
T2（单点 vs 体系） 决定「语言」：沿用姚明流程，不新建
        ↓
T3（全球 vs 本土） 决定「边界」：全球只归萤火虫长期轴
```

**读法**：T4 是约束、T1 是入口、T2 是话术、T3 是禁区。
四条张力 **全部 CONDITIONAL** —— 任何一条被三问打翻，提案形态就要改，而不是硬推。
