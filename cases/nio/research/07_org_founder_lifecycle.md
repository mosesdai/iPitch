# 07 · 组织 / 创始人生命周期（v1.6）

> **本章任务**：判断 NIO 现在处于什么组织阶段——因为 **同一个提案在「求生期」和「体系化期」的命运完全不同**。
> **纪律**：组织内部动作多为媒体口径（**C**）；一切汇报线与流程判断标 **推断**。

---

## 2. 阶段判断（本章硬结论）

**NIO 当前 = 「刚上岸 + 品牌澄清 + 多品牌协同未完成」的三重叠加期。**

| 维度 | 状态 | 证据 |
|------|------|------|
| 财务 | **刚上岸**（Non-GAAP 转正、GAAP 仍亏） | Q1 2026 A |
| 品牌 | **澄清期**（自己定义的阶段） | 李斌表述 C |
| 组织 | **多品牌协同进行中** | 三品牌交付分化 A |
| 体育 | **两个接口 + 一个空缺 + 零协同** | `03` |

**对提案的含义（三条）**：

1. **不能卖「扩张」**：他们不在扩张期，任何「趁势加大投入」都会被判为不懂公司。
2. **可以卖「体系化」**：这是他们自己阶段论里的下一格，语言是通的。
3. **必须自带停损**：刚上岸的公司对不可逆承诺极度敏感。

## 4. 组织能力：他们自己能做什么 / 做不到什么

| 能力 | 自建强度 | 我方能补什么 |
|------|----------|--------------|
| 用户社群运营 | **很强** | 补不了，也不该补 |
| 自有 IP 造节（NIO Day） | **很强** | 补不了 |

| 青年潮流文化触点 | **弱 / 空缺** | **可补**：萤火虫线完全空白 |
| 跨品牌统一叙事架构 | **弱**（三条各自跑） | **可补**：这是本案的核心供给 |
| 外部公信力背书 | 中 | 可补 |

→ **诚实结论**：我们能提供的东西只有三样：**跨品牌架构、青年文化触点、外部公信力**。其余都是他们自己做得更好的事。提案里写多了，会显得不懂对方。

## 5. 决策流（**全部推断 · 须 L0**）

```
条线提案（马麟/沈斐线）
  → 品牌调性把关（秦力洪线）
  → Spirit 一致性（李斌线，涉及跨品牌时）
  → 额度与核销（曲玉线）
```

| 环节 | 我方最容易死在哪 |
|------|------------------|
| 条线 | 提案不可执行 / 太抽象 |
| 调性 | 长得像曝光包 |
| Spirit | 一套素材打三品牌 |
| 财务 | 没有停损点 |

**四道都可能死。刀子只有 10 分钟，因此只解决第一道与第三道；财务那道靠「默认不报价 + 自带停损」绕开。**

## 10. 加厚 · 组织记忆如何决定采购标准（本章方法论核心）

一家公司的采购标准，往往不是由当前战略决定，而是 **由它活下来那一次的经验决定**。

| 组织记忆事件 | 留下的标准 | 对我方的含义 |
|--------------|------------|--------------|
| **2019 现金流危机 + 卖 FE** | 「非核心的重资产，该退就退」 | 任何有 **固定长期支出** 味道的方案都会被下意识排斥 |
| 换电网络的长期投入 | 「基础设施可以长期投，营销活动不行」 | 我方要把方案说成 **可复用的资产**，而不是一次性活动 |
| 用户社群带来的口碑 | 「用户参与比广告有效」 | **可参与性是硬门槛**，不是加分项 |
| 2023–24 多品牌化 | 「每个品牌要有自己的脸」 | 一套素材三处投 = 违背组织信念 |
| 2025 Q4 首次单季 GAAP 转正 | 「纪律有用，别放松」 | 上岸后反而更紧，不是更松 |

**最后一条最反直觉**：外部普遍以为「盈利了就该花钱了」。组织记忆的逻辑相反 —— **刚证明纪律有效的组织，会更信纪律**。这是本案禁止用「交付新高」催单的深层原因。

## 11. 加厚 · 三品牌组织的「三个不」

| 不 | 含义 | 提案约束 |
|----|------|----------|
| **不共用素材** | 三个品牌的脸不能混 | 架构复用、素材独立 |
| **不共用指标** | 合并 KPI 等于没人负责 | 每层指标各自独立 |
| **不共用节奏** | 同城同期撞车会内耗 | 场次错周排布 |

这「三个不」是把「分层」从口号落成执行的最小规则集。会面里可以只说第一条（最好懂），后两条留给第二次会。

## 12. 加厚 · 组织阶段判断的自我检验

我方判断「刚上岸 + 澄清期 + 协同未完成」。如果这个判断错了，会错在哪？

| 可能的误判 | 若为真 | 我方该怎么改 |
|------------|--------|--------------|
| 其实已进入扩张期（内部有大预算） | 我方过度保守，报得太小 | 认方向后 L0 会暴露；届时再放大，**不在第一次会面赌** |
| 其实仍在求生期（比外界更紧） | 连小额试验也批不了 | 转为长期关系维护 |
| 三品牌其实高度集中管理 | 分层是伪需求 | 三问 #1 直接验，PIVOT 单品牌 |
| 体育已有内部主人且在推进 | 我方 timing 错 | 主动退让一个周期 |

**结论**：四种误判里有三种通过 **三问就能当场纠正**，一种（第一种）只会让我方少赚、不会让我方犯错。**这是一个不对称有利的设计** —— 保守的代价小，激进的代价大。

## 13. 加厚 · 组织面【待核实】清单

| # | 项 | 影响 |
|---|-----|------|
| 1 | 是否存在统管三品牌营销的机构或岗位 | 决定分层假设成立与否 |
| 2 | 体育 / IP 类支出的审批层级与 SLA | 决定第二次会面带谁 |
| 3 | 三品牌营销预算的分配机制 | 决定第一试验对象 |
| 4 | 区域（城市）团队的自主权 | 决定一城一试怎么落 |
| 5 | 复盘文化：项目未达标是否真会停 | 决定停损条款是否可信 |

**第 5 项最容易被忽略**：如果这家公司文化上做不到「真停」，那么「不达标即停」这条对他们不是安全感，而是麻烦。**这一条必须当面试探，不能假设。**

## 15. 加厚 · 「可对话主题」vs「禁主题」

| 可对话 | 禁 |
|--------|-----|
| 三品牌各自的人群与语言 | 三品牌之间的资源之争 |
| 用户参与型活动的经验 | 车主社群的具体数据 |
| 姚明与申花两条路径 | 姚明合作的商业条款 |
| 澄清期与体系化 | 「决赛圈」「谁会被淘汰」 |
| 长期主义与停损并存 | 2019 危机细节 |
| 交付节奏与新车效应 | 未达指引、月度排名 |

**判定规则**：凡是 **只有内部人才有资格评价** 的事（人事、条款、内部数据），一律禁。凡是 **他们已经公开讲过** 的框架（Spirit、澄清期、用户企业），一律可用他们的词接着讲。
