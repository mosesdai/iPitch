# 09 · 查了但会面不说（v1.6）

> **原则**：冰山 **50% 以上不进 pitch**。本文件是防「胖刀」与防「装懂」的闸门。
> **用法**：会面前最后 5 分钟扫一遍这张表，比背话术有用。

| 追问 | 回答 |

## 8. 加厚 · 「不说」的四个层级（不是一刀切）

| 层级 | 含义 | 例子 |
|------|------|------|
| **L-A 绝不说** | 说了当场废 | 未核实排他、CPM 开场、审判式引用、当场报价 |
| **L-B 不主动说，被问才说** | 事实可靠但语气危险 | Q2 与指引的差、乐道环比回落幅度、2025 全年待核实数 |
| **L-C 只在第二次会说** | 需要方向确认在前 | 一城一试草图、指标设计、内容资产归属 |
| **L-D 只在内部说** | 用于降低我方预期 | 2020–25 体育安静期、F-6、单车收入代理 |

**为什么要分四层**：一份只有「不说清单」的材料会让销售在现场过度紧张，什么都不敢讲。**分层之后，销售知道哪些是「留着」，哪些是「烧掉」。**

## 9. 加厚 · 三个最容易失手的瞬间

| 瞬间 | 危险 | 预置动作 |
|------|------|----------|
| **对方沉默三秒** | 销售本能补话，常常补出金额或承诺 | 预置一句安全填空：「这个问题你们内部大概谁来定？」 |
| **对方点头认同** | 顺势推三层打包 | 预置：只推进到「约 30 分钟」，不加码 |
| **对方质疑数据** | 慌乱引用媒体数字 | 预置：只报 A 源与算式；「这条是媒体转载，我不用它」 |

**这三条比任何话术都重要**：会面失败大多不是因为准备不足，而是因为 **在这三个瞬间说了多余的话**。

## 10. 加厚 · 「不说」与「诚实」的关系

有一类反对意见是：「把不利的东西藏起来，不算诚实。」

本案的处置是：

| 原则 | 落法 |
|------|------|
| **不隐藏事实** | 所有不利事实都在研报里，客户随时可查（`html/research/iceberg.html` 就是全文镜像） |
| **不主动武器化** | 不利事实不用于施压（未达指引、乐道回落） |
| **被问必答** | 对方问到，如实说，包括「我们不知道」 |
| **不装懂** | 所有缺口标【待核实】/【当面问】 |

**结论**：`09` 不是一份「隐瞒清单」，是一份 **「不把事实当武器」的清单**。这两者的区别，就是顾问和推销员的区别。

## 11. 加厚 · 逐条给出「换句话说」（可直接照念）

不说，不等于不谈。同一件事换个说法，就能从武器变成共同事实。

| 原句（禁） | 换句话说（可） |
|------------|----------------|
| 「你们 Q2 没达到自己的指引」 | 「Q2 落在指引下沿附近，同期乐道从 12,029 回到 11,743。」 |
| 「乐道掉了」 | 「破万的峰值还没变成台阶。」 |
| 「你们现金 482 亿，不缺钱」 | 「流动性和已批预算是两件事，所以我们默认小额。」 |
| 「交付新高，该加投入了」 | 「总量在涨，但三条线方向不一样——这时候资源怎么分？」 |
| 「行业都在做体育」 | 「这套逻辑其实只适合多品牌公司，未必适合别家。」 |
| 「我们有多少粉丝」 | 「我们能补的只有三样：架构、青年触点、外部公信力。」 |
| 「姚明不够」 | 「姚明是灯塔。灯塔下面有没有每周能开张的摊位？」 |
| 「乐道需要帮助」 | 「我们关心的不是行不行，是峰值怎么变台阶。」 |
| 「给你们做排他」 | 「条款层今天不谈。」 |
| 「效果我们保证」 | 「我们只承诺过程：场次、内容、复盘。不达标即停。」 |

**这张表是本文件最实用的一页**：会前把左列遮住，只读右列，就是完整的安全话术。

## 12. 加厚 · 「明确不说」为什么要写给客户看

本案的 `html/research/iceberg.html` 是 **全文镜像**，也就是说客户如果翻研报，会看到这份「不说清单」。这是刻意的。

| 效果 | 说明 |
|------|------|
| **证明我们查过** | 不说 ≠ 不知道；清单本身就是研究深度的证据 |
| **证明我们有纪律** | 主动放弃可用的施压工具，比任何承诺都可信 |
| **降低对方防御** | 对方看到「渠道 / 财务敏感项我们不碰」，会更愿意开口 |
| **对内约束** | 写在客户能看到的地方，销售就不敢临场破戒 |

**风险与处置**：客户可能问「为什么这些不说？」正确回答是——「因为它们是你们的事实，不是我们的论据。我们只在被问到时说。」
