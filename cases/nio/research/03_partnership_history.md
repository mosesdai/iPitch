# 03 · 体育 / IP 合作史（v1.6）

> **本章任务**：钉死 NIO 在体育上的 **真实边界** —— 他们做过什么、退出过什么、什么形态被他们接受、什么形态被他们拒绝。
> **纪律**：合作事件多为媒体/百科口径 → **C 级**；只有官网/公告可标 A。**不写未核实的排他条款。**

|------|------|----------|------|
| 2014–2019 | **Formula E 创始车队**；2014-15 赛季车手总冠军 | 技术高端叙事（赛车） | C（百科/媒体） |

## 2. 五条规律（本章硬结论）

1. **退出 FE ≠ 不爱体育**：2019 出售发生在现金流最紧的一年，同期保住的是换电与芯片。结论是 **「不爱非核心烧法」**，不是 **「不爱体育」**。会面若把 FE 说成「你们放弃体育」，会立刻失分。
2. **姚明 = 模板，不是资产**：可复用的部分不是「一个名人」，而是 **「先对齐价值观、后谈条款」的流程**。我们的提案必须能走这条流程，否则一开始就是异类。
3. **申花 = 已验证的第二品牌路径**：乐道走的是 **用户权益 / 球迷开放日 / 社群参与**，不是 CPM 采买。这说明第二品牌 **能批体育预算**，且形态偏 **可参与**。
4. **十年 FSAE = 他们能接受长周期**：只要故事是「人才/长期」，NIO 有耐心。这对「赛季化、可延续」的设计是加分项。
5. **三品牌的体育接口目前是 1 + 1 + 0**：蔚来一个（姚明单点）、乐道一个（申花一条线）、萤火虫 **零**。**空缺本身就是本案的入口。**

## 3. 形态光谱（他们接受 / 拒绝）

| 形态 | 历史证据 | 判断 |
|------|----------|------|
| 自建 IP（NIO Day、蔚来杯） | 长期在做 | **最舒服**：可控、可沉淀用户 |
| 长期人才类支持（FSAE） | 十余年 | **可接受**：预算小、叙事长 |
| 俱乐部合作（申花） | 乐道 2026-01 | **可接受**：以权益/开放日为主 |
| 名人价值观合作（姚明） | 2026-05 | **可接受**：先方向后条款 |
| 赛车队自持（FE） | 2019 退出 | **已被证伪**：重资产烧法不做 |
| 纯流量/曝光采买 | 秦力洪明确反对（见 `02`） | **拒绝** |
| 大额单一冠名 | 无先例；且 GAAP 仍亏 | **大概率拒绝** |

→ 我们要提的东西必须落在 **前四行**，且不能长得像 **后三行**。

## 10. 加厚 · 2020–2025「体育安静期」的含义（本章最重要的一节）

从 2019 年出售 FE 车队运营，到 2026-01 乐道 × 申花，中间有 **五到六年** 的公开体育动作稀薄期。这段空白通常被研究者忽略，但它是本案 **最强的反证来源**。

**三种解释，三种后果**：

| 解释 | 如果为真 | 我方后果 |
|------|----------|----------|
| **① 资源被吃掉**：换电网络、多品牌开发占用全部预算 | 体育不是不做，是排不上 | **可谈**：小额试验正好绕开排期 |
| **② 战略性不做**：认为自建社群比外采 IP 高效 | 体育采购在这家公司结构性缺位 | **难谈**：需要重新定义「不是采购，是共建」 |
| **③ 没有对口的人**：无单一 CMO，无人负责外部 IP | 不是不想，是没人接 | **可谈但要慢**：第一步是找 owner，不是提案 |

**我方不知道是哪一种。** 这就是 `../ifalsify_report.md` 里 **F-6** 的来源，也是三问 #3 要探的东西。

**纪律**：**不要在会面里点出这段空白**。说「你们六年没做体育」等于当面质疑对方的历史选择。这一节只在内部使用，用来降低我方对成交概率的预期。

## 11. 加厚 · 姚明模板的可复制部分与不可复制部分

| 要素 | 可复制？ | 说明 |
|------|----------|------|
| 「先价值观，后条款」的流程 | **可** | 我方提案必须走同一流程，否则是异类 |
| 精神层的符号强度 | **不可** | 没有第二个姚明 |
| 与单一车型绑定 | **不该复制** | 单点化正是我方要解的问题 |
| 由品牌传播条线主导 | 部分 | 取决于三条线是否分家（三问 #1） |
| 无条款拉扯的谈法 | **可** | 意味着第一次会面 **不该带合同** |

**推论**：我方第一次会面的正确形态，就是 **姚明案的形态** —— 只谈方向、不谈条款。这不是我方的风格选择，是 **对方已经示范过的流程**。照着走，成本最低。

## 12. 加厚 · 申花模板的四个可迁移动作

申花案在公开层面能看到的动作（C 级），拆成可迁移单元：

| 动作 | 可迁移到篮球的形态 | 归属品牌 |
|------|--------------------|----------|
| 官方座驾 | 球队 / 赛事用车与出行场景 | 乐道 |
| 球迷开放日 | **家庭 / 亲子篮球日** | 乐道 |
| 主场露出 | 场地与内容露出（次要） | 乐道 |
| 社群联动 | 车主社群 × 球迷社群互开 | 乐道 + 蔚来 |

**关键判断**：申花案里最有价值的不是露出，是 **开放日** —— 因为它是唯一 **能核销到「到店 / 参与人数」** 的动作。我方提案的重心应当放在这一格，而不是露出。

## 13. 加厚 · 体育合作与「用户企业」模型的耦合点

NIO 的用户企业模型意味着：**任何外部活动如果不能让车主参与，就无法进入他们的运营飞轮。**

| 耦合点 | 设计要求 |
|--------|----------|
| 车主可报名 | 场次必须有车主席位或优先权 |
| 可产生 UGC | 现场要有可拍、可传的内容点 |
| 可沉淀到 App / 社群 | 活动后有内容归档与二次传播路径 |
| 可被区域复制 | 单城做完能给别的城市抄 |

**反面清单**：只有观赛权益、只有 VIP 席、只有品牌露出的方案，在这套模型里 **是死的** —— 它没有给用户任何可参与的动作。

## 10. 深读 A · 合作史的四层结构（本章独有）

把十二年的体育与 IP 动作按「**买的是什么**」重排，会看到钱一直花在同一个方向上，而且**越来越往下走**。

| 层 | 买的是什么 | NIO 的动作 | 现在是否仍在延续 |
|----|------------|------------|------------------|
| L4 · 技术背书 | 工程能力的公开证明 | Formula E 创始车队（2014–19）、FSAE 支持（2009–今） | 部分（FSAE 在，FE 已退运营） |
| L3 · 声量与曝光 | 人群覆盖 | FE 冠名保留至 2023；常规传播 | **弱化**（与反爆款立场一致） |
| L2 · 社群与共创 | 用户参与与留存 | 蔚来杯用户足球、乐道×申花球迷开放日 | **在加强** |
| L1 · 精神与价值观 | 品牌内核的可复述性 | 姚明 ES9 首席体验官（2026-05-27） | **最新一步** |

**读法**：L4 → L1 是一条**从证明产品到证明品牌**的路径。这条路径同时解释了两件看似矛盾的事：2019 年为什么能毫不犹豫卖掉 FE 车队运营（L4 已经买够了），2026 年为什么会在半年内同时出现姚明与申花（**澄清期需要的是 L1 和 L2**）。

**对提案的硬含义**：任何以 **L3 为主体**的方案，在这条曲线上是**倒退**。我们能站住的位置只有两个——把 L1 做成**可复用模板**，或把 L2 做成**可核销系统**。

## 11. 深读 B · 姚明案 vs 申花案的逐项拆解

这两个案子是本轮**唯二可用的内部先例**。它们的**差别**比共同点更有信息量。

| 维度 | 姚明 × 蔚来 ES9（2026-05） | 乐道 × 上海申花（2026-01） |
|------|-----------------------------|-----------------------------|
| 品牌线 | 蔚来主品牌 · 高端 | 乐道 · 家庭 |
| 主导线索（C） | 马麟（品牌传播条线） | 乐道品牌线（**归属待 L0**） |
| 买的层 | **L1 精神** | **L2 社群** |
| 交付物形态 | 身份/角色 + 车型绑定 | 球队座驾 + 球迷开放日 + 属地活动 |
| 谈判起点（转述 C） | **先谈价值观，无条款拉扯** | 权益 + 用户活动组合 |
| 可复用性 | **弱**（人格资产，姚明只有一个） | **强**（换球队、换城市即可） |
| 可核销性 | **弱**（品牌资产难直接归因） | **较强**（到店/试驾/社群活跃可测） |
| 对我们的用处 | 提供**立项语言** | 提供**执行结构** |

**关键推论（推断 · 须 L0）**：只学姚明案 → 得到一个漂亮但**无法核销**的提案，卡在曲玉闸门；只学申花案 → 得到一个可核销但**没有精神高度**的提案，卡在「走心」那一关。

> **唯一可能同时过两关的形态**：用**姚明案的语言**立项（价值观先行、不先谈条款），用**申花案的结构**落地（一城一线一指标、不达标即停）。这一句是本章对刀刃最重要的输出。

## 12. 深读 C · 从合作史反推「他们的立项条件」

公开材料不会给我们评审表，但**做过什么**本身就是评审表的投影。

| 反推出的条件 | 证据（合作史） | 违反后的后果 |
|--------------|----------------|--------------|
| 必须能装进**某一个**品牌的 Spirit 叙述 | 姚明→敢想有为；申花→轻松家庭 | 「不知道这是给谁做的」→ 立项会被打回 |
| 必须有**用户可参与**的一环 | 蔚来杯、球迷开放日 | 被归为「纯投放」 |
| 必须能在非核心时**果断退出** | 2019 卖 FE 运营、冠名留到 2023 | 长约无退出条款 = 财务不批 |
| 不能只有**一次性峰值** | FSAE 十五年、用户足球多年 | 一次性活动进不了长期资产 |
| **不能让品牌之间互相稀释** | 姚明只落蔚来、申花只落乐道 | 一套素材打三线 = 直接踩线 |

**注意最后一行**：这不是我们的主张，是从他们**已经做过的事**里读出来的——两个案子**刻意分开**落在两个品牌上。这是「分层」在公开材料里最硬的一块支撑。

## 13. 深读 D · 2020–2025 的体育「安静期」怎么读

从 FE 退出运营（2019）到乐道×申花（2026-01），中间是一段公开体育动作稀薄的时期。很容易误读成「他们不重视体育」。更贴近证据的三种读法：

1. **资源被产品与网络吃掉**：这段时间是多品牌（乐道、萤火虫）与换电网络扩张期，资本开支优先级压倒外部品牌投放。
2. **用户运营替代了体育**：NIO Day、社区与用户赛事本身承担了「社群」职能，外部体育 IP 的边际价值不高。
3. **危机后的资本纪律固化**：2019 之后形成的「非核心果断退出」惯性，长期抬高了长约体育资产的立项门槛。

**含义**：安静期不是冷淡，是**优先级**。2026 年重新出现两个体育动作，说明优先级刚刚变化——**这是窗口**；但同时也说明**没有历史预算基线**，绝不能拿「他们一直有体育预算」当假设。

## 14. 深读 E · 若要把申花模板换项目、换城复制，需要什么

这是会面最可能被追问的一段，必须提前想清楚（**以下为思路，不是承诺；金额与权益一律留白**）。

| 要素 | 申花案里已有 | 换项目/换城需要新增 | 谁定 |
|------|--------------|---------------------|------|
| 属地 IP | 上海本地球队 | 目标城的对应体育触点 | 我方提候选 |
| 品牌线 | 乐道 | 仍建议**单一品牌线**，避免混线 | 客户定 |
| 用户触点 | 球迷开放日 | 家庭场景的可参与设计 | 双方共创 |
| 主指标 | 【未公开】 | 到店 / 试驾 / 社群活跃 / 品牌提升 **四选一** | **客户定** |
| 停损 | 【未公开】 | 判定期与阈值，写进立项 | 双方 |
| 预算 | 【未公开】 | **不谈**（L0 未闭） | — |

**六格里有三格是 L0**。这本身就是会面必须先拿三问的理由：不是我们没想清楚，而是这三格公开源**永远拿不到**。

## 15. 深读 F · 合作史的三条禁用推论

| 禁用推论 | 为什么错 |
|----------|----------|
| 「他们做过 FE，所以有大额体育预算」 | FE 是 2014–19 另一种公司状态；2026 的约束（GAAP 仍亏、毛利指引下调）完全不同 |
| 「他们做过姚明，所以名人合作好卖」 | 姚明案的关键是**价值观先行**，不是名人本身；带明星清单进门会被归为「塑料花」 |
| 「申花成了，所以体育在内部已被证明」 | 单案成功 **≠** 内部方法论；能否复制正是三问 #2 要问的 |
