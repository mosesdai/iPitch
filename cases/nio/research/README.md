## 二 · 本案的四条方法论特色

1. **「自算」标注制度**：所有派生数字（+49.4% / −2.4% / +22.7% / −2,342 台）标 **自算** 并给出算式，会面可当场演算。
2. **交付与损益分句**：交付有 2026-06 的 A 源，损益只到 Q1 2026 —— **Q2 财报未披露，宁空不编**。
3. **大盘主动排除**：本轮未取到可信一手大盘 → `12` 不编数字，改用「只用客户自己公布的数字」的替代打法。
4. **不说清单对客户公开**：`09` 随全文镜像可见，证明「不说 ≠ 不知道」，且主动放弃施压工具。
