## 一 · 为什么必须有 L0

公开 A 源能证明的：**交付结构、三品牌行为分化、损益约束、两个已存在的体育接口**。
公开 A 源 **永远不会给** 的：

| 空白 | 为什么公开源没有 |
|------|------------------|
| 体育 / 品牌营销预算是否存在、量级如何 | 财报不单列体育口径 |
| 谁 initiator、谁 veto | 组织分工不公告 |
| 三品牌 KPI 与预算是否分家 | 三品牌 P&L 从未单列 |
| 申花是否含品类 / 项目排他 | 合作细节未公开 |
| 马麟线是否已有 IP 在档 | 不公告 |
| 试点城选择权在总部还是区域 | 不公告 |

→ **没有这六项，任何金额、任何权益包、任何排他表述都是装懂。**

## 二 · 待验证假说

**假说**：三品牌 6 月的行为分化（+9.5% / −2.4% / +22.7%，自算）反映的是 **三条独立的人群命题**；因此体育资源若不分层，会同时得罪蔚来（稀释 Spirit）和乐道（不解决台阶问题）。若我方提案不能 **分层 + 任一层单独成立**，会被归入「又一套三品牌通用曝光」而卡住。

**若真** → 以 **乐道家庭线** 为第一试验对象（申花模板换项目），蔚来只绑精神层 / 姚明桥，萤火虫排二面。
**若假**（KPI 与预算合并、体育由品牌中心统一出） → **discard 三层架构**，改为 **单品牌单场景**试验；主刀切换到 T2（姚明单点 → 体系化）。
**若更坏**（体育根本不在预算表里，反证 F-6 成立） → 本轮 **转诊断会面，不报价**，转长期关系维护。

## 三 · 进门三问（恰好 3 · 与 ONE_PAGER §9 / B_knife 完全一致）

1. **L80 起来之后，乐道这边「家庭破圈」的预算和 KPI，是跟申花一条线，还是另有 owner？**
   - 攻的反证：**F-1**（KPI 不分家 → 分层是伪需求）
   - 若答「另有 owner」→ 分层成立，主试验对象锁定乐道
   - 若答「统一出、KPI 合并」→ **PIVOT** 单品牌单场景

2. **姚明这条，马麟团队定义的成功是 ES9 单点，还是三品牌 Spirit 各有一条可复用模板？**
   - 攻的反证：**F-2**（代言 = 体育已做完）
   - 若答「单点即可」→ **PIVOT** 到内容层或萤火虫青年线

3. **如果做体育 IP，曲玉那边先过的是金额上限，还是 Spirit 一致性？**
   - 攻的反证：**F-4 / F-6**（窗口关着 / 无预算基线）
   - 若答「体育不在预算表里」→ **本轮不报价**，只做诊断

> **三问的设计原则**：每一问的答案都会 **改变我们下一步做什么**，而不是让我们「更了解客户」。
> **提问纪律**：三问之外不追问预算数字；对方主动说才接。
