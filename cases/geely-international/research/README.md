# 吉利国际 · 冰山研究索引

> 版本：v0.2 · 2026-08-26  
> 研究对象：**Geely Auto International Corporation（GAIC / 吉利汽车国际）**  
> 纪律：International、Geely Automobile Holdings（0175.HK）、浙江吉利控股集团（ZGH）三层分开；无一级来源的法人、区域销量、预算和决策权一律标【待核实】。

## 先读：主体边界

1. **Geely Auto International Corporation**：吉利汽车集团公开新闻稿所称的国际业务运营主体。2025-04-29 官方任命 Alex Nan 为 CEO，称其“oversee all international operations”。公开网页显示 GAIC PR 联系方式，但未单独披露完整法定实体、审计财务、董事会或地区 P&L；这些均不能从集团叙述反推。
2. **Geely Automobile Holdings Limited（0175.HK）**：港股上市公司，控制股东为浙江吉利控股；2025 年末旗下三品牌为 Geely、Lynk & Co、ZEEKR。其年报是收入、利润、出口批发量及品牌海外网络的 A 源。GAIC 的经营结果并未作为单独可报告分部披露。
3. **浙江吉利控股集团（ZGH）**：上层私人控股集团及全球出行品牌组合，范围超出 0175.HK，包括 Volvo Cars、Polestar、Lotus、smart 等投资/品牌关系及远程等。控股集团“全球销量”不可当作 GAIC 销量。
4. **对外叙事差异**：GAIC 讲“国际运营、渠道、本地化、伙伴”；0175.HK 讲“上市公司三品牌的规模、盈利与出口”；ZGH 讲“One Geely”、全球品牌组合、技术/资本协同。三者可协同，不能合并成一个采购中心。

## 国际业务四条分轨

| 轨道 | 本案口径 | 不可偷换 |
|---|---|---|
| Geely 品牌出口/本地化 | GAIC 主线；EX5/EX2/Starray EM-i、Coolray、Emgrand；代理、分公司、CKD/本地生产 | 不等于整个控股集团 |
| Lynk & Co | 0175.HK 品牌线；2025 年海外门店与出口单列 | 不自动归 GAIC 同一预算 |
| ZEEKR | 0175.HK 高端新能源品牌线；独立门店/市场打法 | 不可把极氪高端客群套给 Geely |
| Volvo/Polestar/Lotus/smart/PROTON | ZGH 全球组合或伙伴线，各自治理、股权与渠道不同 | 不视为 GAIC 可随意调用资产 |

## 当前研究结论

**吉利国际正在从“把车交给海外代理”升级为“把多能源产品、渠道、服务和本地生产一起装进市场”，但它公开可见的组织仍是按国家、伙伴和品牌拼接；真正稀缺的不是又一个全球曝光，而是能让总部、区域、经销商用同一套证据学习且不抹平地方差异的国际运营资产。**
