# Vision Card · Trust Passport Network

> 产品代号：P-GAIC-B-TPN · Stage: Experiment

## 一句话

**把“全球技术、本地制造、当地服务”从品牌片里的三句话，变成每家 dealer 每次都能兑现的四枚信任章。**

## 旧品类 → 新品类

| 旧品类：launch / test-drive campaign | 新品类：Trust Passport Network |
|---|---|
| 看完片、留线索 | 完成与个人顾虑对应的 proof |
| 销售顾问自由讲 | 证据任务与责任人标准化 |
| 只看试驾量 | 看证据完成→订单→交付→首保 |
| 全球卖点堆叠 | 国家合法、车型真实、当地可兑现 |
| 活动结束即消失 | 护照跟随用户到交付和首保 |

## Job

> 当一个新市场消费者担心“新品牌是否安全、能不能充/省、坏了谁修、几年后值不值”时，让 dealer 用可验证证据完成信任，而不是靠更大声的品牌承诺。

## 四枚信任章

1. **Build**：该车真实生产/组装来源、PDI 与质量责任；
2. **Use**：当地合法配置、能耗/充电或混动适配；不拿中国功能冒充；
3. **Care**：保修、零件、维修、救援、金融/保险责任；
4. **Belong**：本地车主/伙伴证据与问题闭环。

## Why now

- Geely 新能源出口结构快速增长；
- Europe/Brazil/Indonesia/South Africa 等新市场同时扩张；
- Egypt、Indonesia、Brazil 的本地化可以成为信任证据；
- South Africa 已经组建金融、充电、物流、救援伙伴栈；
- 网络数量很大，但 production / satisfaction 指标公开不可见。

## 首个 pilot 选择

### Option 1 · Poland / Italy

新品牌+代理+欧洲信任门槛。围绕 EX5，dealer 证明安全、充电、保修、服务与残值路径。

### Option 2 · Brazil

把 Renault 合作从企业新闻变成责任图；未量产前严格区分进口车与未来本地生产。

### Option 3 · Indonesia

把本地组装和多能源适配变成 ownership proof；右舵 spec 逐车型核验。

## 12 周设计

- 6–10 家 treatment dealer + 可比 control；
- 用户试驾前选择最大顾虑；
- 顾问只触发对应 proof，不做信息轰炸；
- 护照进入 CRM，交付/30 天/首保继续更新；
- 每周复盘未完成 proof 与 lost reason。

## 验收指标

| 指标 | 说明 | 初始门槛 |
|---|---|---|
| Proof completion | 选定顾虑完成对应证据 | ≥75% |
| Explanation accuracy | 顾问不夸大配置/责任 | ≥90% 抽检 |
| Test drive→next step | 订单/金融预审/二次到店 | 相对 control 正向 |
| Lost reason capture | 可分类失败原因 | ≥80% |
| Handoff SLA | dealer→finance/charging/service | 比 baseline 改善 ≥25% |
| 30-day issue closure | 首批车主问题按承诺关闭 | 阈值由当地 SLA 预注册 |

> 以上是实验门槛，不是现状或预测。

## Kill

- 售后/零件/金融不参加；
- 证据不可兑现或不允许审计；
- dealer 只想扫码留资；
- 不区分进口与本地生产；
- control 无法建立；
- 指标只剩曝光。

## 商业模式

按市场安装 **proof design + dealer training + CRM fields + partner handoff + audit**。成功后可扩 outlet；不靠一次大型 event 收费。
