# Job Map · Trust Passport Network

## When

- Geely 是当地新进入品牌；
- 产品技术卖点多，但消费者首要顾虑是 ownership；
- dealer、金融、充电、物流、救援由不同伙伴负责；
- 本地组装/伙伴合作已经发生，却只存在新闻稿；
- 销售线索很多，lost reason 与售后信任不可见。

## Want

Country GM / channel / after-sales 想：

> “不要再告诉我全球有多少用户；我要每个顾问都能准确回答这台车在这里谁生产、谁修、多久有件、充电/混动怎么用，并看到这是否让客户迈出下一步。”

## But：今天 hire 的烂方案

| hire | 得到 |
|---|---|
| launch event | 首周声量，无长期责任 |
| influencer test drive | 体验内容，未必回答售后 |
| dealer training deck | 学完不等于会讲/讲对 |
| lead-gen media | 名单增多，信任阻力不明 |
| loyalty club | 通常在交付后才开始 |
| warranty brochure | 静态条款，不连接 handoff |

## Struggling moment

> 客户在展厅问“电池有问题谁负责、零件多久到、这是进口还是本地装？”销售顾问打开三份 PDF，金融/充电/售后各给一个号码。品牌说自己有完整生态，客户体验到的是五个接口。

## New job to be done

**Install a trust proof network**：把品牌、工厂、dealer、金融、充电、售后共同变成一次连续、可追踪、可审计的 ownership 承诺。

## Functional jobs

1. 识别个人最大顾虑；
2. 匹配当地合法/真实 proof；
3. 指定责任伙伴；
4. 完成试驾/金融/服务 handoff；
5. 记录未完成与 lost reason；
6. 跟随交付与首保；
7. 将高频阻力反馈产品/运营；
8. 审计销售顾问是否夸大。

## Emotional jobs

- 消费者敢买一个新品牌；
- 顾问不靠背话术建立专业感；
- dealer 不被 global campaign 压 KPI；
- 伙伴知道自己在完整旅程中的责任；
- 总部看到“信任”如何变成行为。

## Social jobs

- 本地组装不只是政策故事，而是体面的当地贡献；
- 车主愿意用真实 ownership 证据推荐；
- 新品牌从“便宜中国车/科技新奇”转为“有人负责”。

## 不做什么

- 不做 NFT / 区块链噱头；
- 不收集超出 consent 的个人数据；
- 不承诺固定残值；
- 不把未来工厂写成现状；
- 不把中国 ADAS/软件功能复制到海外；
- 不以领取护照人数作为成功。

## 关键依赖

- country GM 与 after-sales co-owner；
- dealer training / CRM；
- 零件、保修、救援、金融真实 SLA；
- 国家车型规格与合规；
- control；
- 30 天以上问题闭环。
