# Geely International · disruptive - 跳出盒子 双创意

> disruptive - 跳出盒子 路径：不是“帮你出海”，而是给国际运营新增两个过去无法采购的按钮。两个概念均先做 12 周实验；无 baseline 不启动。

| | A · World+ Market Twin | B · Trust Passport Network |
|---|---|---|
| Job | 总部与国家共享学习，而非共享一套答案 | 把全球技术/本地承诺变成 dealer 可兑现的信任动作 |
| 旧品类 | global campaign / 内容本地化 / 季度市场报告 | launch event / 品牌片 / 一次试驾 |
| 新品类 | **跨市场学习孪生体** | **所有权信任护照网络** |
| 首选区域 | Indonesia + Italy/Poland 两个差异市场 | Europe 新市场或 Brazil |
| 主 buyer 假说 | GAIC CEO / international strategy / regional operations | country GM / channel / after-sales |
| 主指标 | learning cycle、market adoption、试驾/订单 uplift | 证据完成率、试驾→订单、首保/转介绍 |
| Kill | 不给 baseline；只要 campaign；无国家 owner | 售后不参与；承诺不可兑现；只看曝光 |

## 为什么是两个

**A 修总部—区域之间的学习协议；B 修消费者—dealer 之间的信任兑现。**  
A 能让 World+ 不变成各自为战，B 能让网络覆盖不止是地图上的点。二者可以组合，但首面只推一个。

## 使用顺序

1. 国际战略 / Alex Nan 场：A 为主；
2. 区域 GM / channel / after-sales 场：B 为主；
3. 若 A pilot 发现最大共同阻力是 ownership trust，再把 B 作为第二层；
4. 若客户只要全球 IP 曝光，不接本案。

## 共同纪律

- Geely、Lynk & Co、ZEEKR 分账；
- Volvo/PROTON 等资产未经授权不调用；
- 国家法规与车型配置逐项核；
- 指标必须进入 CRM / 服务系统；
- control + kill；
- 12 周后只凭行为扩展，不凭汇报好看。
