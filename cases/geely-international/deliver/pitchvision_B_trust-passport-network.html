Job Map · Trust Passport Network

Job Map · Trust Passport Network

When

  • Geely 是当地新进入品牌；
  • 产品技术卖点多，但消费者首要顾虑是 ownership；
  • dealer、金融、充电、物流、救援由不同伙伴负责；
  • 本地组装/伙伴合作已经发生，却只存在新闻稿；
  • 销售线索很多，lost reason 与售后信任不可见。

Want

Country GM / channel / after-sales 想：

“不要再告诉我全球有多少用户；我要每个顾问都能准确回答这台车在这里谁生产、谁修、多久有件、充电/混动怎么用，并看到这是否让客户迈出下一步。”

But：今天 hire 的烂方案

hire得到
launch event首周声量，无长期责任
influencer test drive体验内容，未必回答售后
dealer training deck学完不等于会讲/讲对
lead-gen media名单增多，信任阻力不明
loyalty club通常在交付后才开始
warranty brochure静态条款，不连接 handoff

Struggling moment

客户在展厅问“电池有问题谁负责、零件多久到、这是进口还是本地装？”销售顾问打开三份 PDF，金融/充电/售后各给一个号码。品牌说自己有完整生态，客户体验到的是五个接口。

New job to be done

Install a trust proof network：把品牌、工厂、dealer、金融、充电、售后共同变成一次连续、可追踪、可审计的 ownership 承诺。

Functional jobs

  1. 识别个人最大顾虑；
  2. 匹配当地合法/真实 proof；
  3. 指定责任伙伴；
  4. 完成试驾/金融/服务 handoff；
  5. 记录未完成与 lost reason；
  6. 跟随交付与首保；
  7. 将高频阻力反馈产品/运营；
  8. 审计销售顾问是否夸大。

Emotional jobs

  • 消费者敢买一个新品牌；
  • 顾问不靠背话术建立专业感；
  • dealer 不被 global campaign 压 KPI；
  • 伙伴知道自己在完整旅程中的责任；
  • 总部看到“信任”如何变成行为。

Social jobs

  • 本地组装不只是政策故事，而是体面的当地贡献；
  • 车主愿意用真实 ownership 证据推荐；
  • 新品牌从“便宜中国车/科技新奇”转为“有人负责”。

不做什么

  • 不做 NFT / 区块链噱头；
  • 不收集超出 consent 的个人数据；
  • 不承诺固定残值；
  • 不把未来工厂写成现状；
  • 不把中国 ADAS/软件功能复制到海外；
  • 不以领取护照人数作为成功。

关键依赖

  • country GM 与 after-sales co-owner；
  • dealer training / CRM；
  • 零件、保修、救援、金融真实 SLA；
  • 国家车型规格与合规；
  • control；
  • 30 天以上问题闭环。

Vision Card · Trust Passport Network

Vision Card · Trust Passport Network

产品代号：P-GAIC-B-TPN · Stage: Experiment

一句话

把“全球技术、本地制造、当地服务”从品牌片里的三句话，变成每家 dealer 每次都能兑现的四枚信任章。

旧品类 → 新品类

旧品类：launch / test-drive campaign新品类：Trust Passport Network
看完片、留线索完成与个人顾虑对应的 proof
销售顾问自由讲证据任务与责任人标准化
只看试驾量看证据完成→订单→交付→首保
全球卖点堆叠国家合法、车型真实、当地可兑现
活动结束即消失护照跟随用户到交付和首保

Job

当一个新市场消费者担心“新品牌是否安全、能不能充/省、坏了谁修、几年后值不值”时，让 dealer 用可验证证据完成信任，而不是靠更大声的品牌承诺。

四枚信任章

  1. Build：该车真实生产/组装来源、PDI 与质量责任；
  2. Use：当地合法配置、能耗/充电或混动适配；不拿中国功能冒充；
  3. Care：保修、零件、维修、救援、金融/保险责任；
  4. Belong：本地车主/伙伴证据与问题闭环。

Why now

  • Geely 新能源出口结构快速增长；
  • Europe/Brazil/Indonesia/South Africa 等新市场同时扩张；
  • Egypt、Indonesia、Brazil 的本地化可以成为信任证据；
  • South Africa 已经组建金融、充电、物流、救援伙伴栈；
  • 网络数量很大，但 production / satisfaction 指标公开不可见。

首个 pilot 选择

Option 1 · Poland / Italy

新品牌+代理+欧洲信任门槛。围绕 EX5，dealer 证明安全、充电、保修、服务与残值路径。

Option 2 · Brazil

把 Renault 合作从企业新闻变成责任图；未量产前严格区分进口车与未来本地生产。

Option 3 · Indonesia

把本地组装和多能源适配变成 ownership proof；右舵 spec 逐车型核验。

12 周设计

  • 6–10 家 treatment dealer + 可比 control；
  • 用户试驾前选择最大顾虑；
  • 顾问只触发对应 proof，不做信息轰炸；
  • 护照进入 CRM，交付/30 天/首保继续更新；
  • 每周复盘未完成 proof 与 lost reason。

验收指标

指标说明初始门槛
Proof completion选定顾虑完成对应证据≥75%
Explanation accuracy顾问不夸大配置/责任≥90% 抽检
Test drive→next step订单/金融预审/二次到店相对 control 正向
Lost reason capture可分类失败原因≥80%
Handoff SLAdealer→finance/charging/service比 baseline 改善 ≥25%
30-day issue closure首批车主问题按承诺关闭阈值由当地 SLA 预注册

以上是实验门槛，不是现状或预测。

Kill

  • 售后/零件/金融不参加；
  • 证据不可兑现或不允许审计；
  • dealer 只想扫码留资；
  • 不区分进口与本地生产；
  • control 无法建立；
  • 指标只剩曝光。

商业模式

按市场安装 proof design + dealer training + CRM fields + partner handoff + audit。成功后可扩 outlet；不靠一次大型 event 收费。
