# PRIMARY_REQUIRED · 雀巢中国

| 字段 | 值 |
|------|-----|
| tier | B |
| 状态 | **open** |
| 阻塞 | Economic Buyer、试验预算上限、美禄代言在档、经销商/运营商评价、佳得乐品类边界 |

## 为何需要 L0

外部 L2 能证明：FY25 校正年、H1-26 demand-led/stable、美禄×易建联、咖啡要 IP。  
但 **2026 非代言类场景试验预算是否放开、马凯思是否见外部体育伙伴、咖啡与美禄 KPI 是否分账、渠道是否接受零进货绑赠**，不会出现在集团 IR。

## 待验证假说

**假说**：客户需要的是 demand-led 下的多品牌（先咖啡+美禄）可核销场景 OS，不是下一张代言合同。  
**若真**：谈样板城 + 分品牌 KPI + 不达标即停。  
**若假**（客户认为易建联+数字广告已闭环 / 只想要曝光报价）：discard OS，或结束。

## 销售 checklist（首面后 72h）

- [ ] 客户 business problem 原话（是否复述 demand-led / sell-out）  
- [ ] 见面人 = 马凯思线 / 咖啡 BU / 徐福记·美禄 / 财务 / 媒介代理 / 其他  
- [ ] 体育/IP 决策：initiator / veto / AOA 是否插手  
- [ ] 2026 **非代言类**场景试验预算有无、上限数量级  
- [ ] 美禄×易建联合约是否在档、品类排他  
- [ ] 经销商/运营商对「运动/IP 战役」评价（有用 / 没用 / 添乱）  
- [ ] #1 顾虑：钱 / 渠道价盘 / 佳得乐冲突 / 跨 BU 协同 / 总部审批慢  
- [ ] 样板城偏好（沪深蓉等）与可否零进货绑赠  

## 会面三问（进门只带这三句）

1. 「咖啡和美禄，KPI 与预算是不是**两条线**？体育/IP 算谁的账？」  
2. 「Demand-led 考核里，外部合作算 **sell-out / 品牌力**，还是还在看经销商进货？」  
3. 「库存校正完成后，2026 国内**非代言类**场景试验是冻结、单列，还是必须挂增长平台才批？」
