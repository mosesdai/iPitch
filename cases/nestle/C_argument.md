# Layer C · 论证备答 · 雀巢中国

## 若问：你们不就是卖曝光吗？

答：我们谈的是 **sell-out 与可复用场景资产**，对齐你们 IR 的 demand-led。美禄已经证明篮球明星能用；我们补的是**跨品牌操作系统**，不是多买一次 KOL。

## 若问：有易建联还不够？

答：够美禄一季战役，不够咖啡日频场景，也不够把「难忘传播」变成可复制能力。单点代言 ≈ 你们要告别的「碎片推货思维」的营销版。

## 若问：和佳得乐冲突吗？

答：我们建议接口落在**咖啡与运动零食**，不碰电解质运动饮料主叙事。场域可以同在篮球，品类不必对撞。

## 若问：Q2 已经 +2% 了还急什么？

答：IR 自己写了 categories still negative；+2% 含基数效应。窗口是「稳定后选发动机」，不是「已经翻盘」。

## 若问：预算多少？

答：冷启动不报价。先认方向与试验边界；数字进 D 层、有 L0 后再谈。

## 若问：为什么是 NBA 不是奥运/CBA？

答：奥运是事件，你们要的是**日常需求频次**。咖啡和零食是周频/日频；联赛赛季更贴 demand-led。CBA 可并存，不在本轮唯一 ask 里展开。

## 若追问 FY25 −6.4%

答：这是校正年事实（A），用来说明**为什么 demand-led 必须做成**，不是来催大赞助。
