## 2. 已有体育资产深读：美禄 × 易建联

**事实（A · 官网 PR）**：

- 产品：美禄**运动力量饼干**（零食，非电解质饮料）  
- 代言人：易建联；主题强调运动场景、青少年与爱好者、「上场」意象  
- 组织落点：**徐福记 / 美禄**线，不等于全公司体育 SOP  
- 同期计划：多场马拉松等大众运动赞助（是否 2025–26 延续 → **【待核实】**）

**解读（标推断）**：

| 维度 | 读法 |
|------|------|
| 证明什么 | 雀巢中国**会买篮球明星**；运动零食心智可做 |
| 不证明什么 | 已有跨 BU 联赛级 OS；已占 NBA 中国赛场域 |
| 对 pitch | 钩子应是「单点 → 系统」，不是「你们该请球星」 |
| 风险 | 代言到期/不续；客户说「有联了够了」；与佳得乐心智混淆 |

**断裂风险清单（美禄线）**：

- 合约是否在档、是否品类排他 → L0  
- 马拉松赞助是否续 → L0  
- 易建联资产是否可延伸到咖啡/营养 → 极可能否；勿默认

## 6. 钩子候选（按锋利度）

1. **首选**：H1-26「库存完成 + demand-led」+ 美禄已用易建联 → 「单点球星 ≠ 需求 OS」  
2. **次选**：咖啡「IP 会越来越多」+ 中国赛场域雀巢缺席 → 「年轻化口令 vs 篮球日常缺席」  
3. **组织钩**：马凯思上任一年内完成库存叙事切换 → 「新班子要用结果语言，不靠再压货」  
4. **慎用**：蒙牛×NBA 对比 → 易变竞品恐吓；最多作横向事实一句  
5. **禁用**：渠道丑闻开场；奥运花费对比；挑战佳得乐运动饮料主叙事

## 11. 合作决策「断裂考古」方法（本案适用）

香飘飘案有长代表言换脸链；雀巢篮球公开链短。方法仍通用：

1. **先列事件卡**（E01–E10）——只写有出处的  
2. **标状态**：现行 / 已结束 / 未知  
3. **断裂原因**：有官方说明才写；否则【待核实】  
4. **禁止**：用竞品动作倒推「雀巢一定做过又停了」  

本案已核实断裂：独立 GCR 取消（架构公告语境）；库存校正年外部合作窗口关闭（IR）。  
未核实：易建联是否续、马拉松是否续、是否有隐秘校园篮球。
