# 横纵完整版 · 雀巢大中华 × 需求拉动力

> v1.2 加厚

## 纵：因果链（时间）

```
高增长年代：分销扩张 → 铺货点数上升 → 报表好看
        ↓
通缩 + 信心弱：压货 / 库存畸高 → 价盘与信任受伤（IR 称 correct trade inventory）
        ↓
2024：仍正 RIG，但 Pricing −2.1%；A&M 升、margin 降
        ↓
2025：组织并入 AOA + 换帅 + FY OG −6.4%
        ↓
集团侧：换 CEO（Navratil）+ 加码营销肌肉 + 四业务聚焦
        ↓
2026 H1：库存校正完成 → 「stable」→ 官宣 demand-led
        ↓
Q2 OG +2.0% 但 categories still negative
        ↓
窗口：用什么引擎真正拉动消费者？数字广告 / 联名 IP / 体育场景 OS / 经销商私域 …
```

**纵结论**：现在是「清理完毕、等待发动机」的半年，不是「危机公关求曝光」的半年。

## 交汇：张力从哪来

```
纵：demand-led 时间窗打开
×
横：篮球需求语言已被乳业/运动饮料占位，雀巢只有单点代言
→
若不变：可见度与「难忘传播」仍靠碎片战役，品类负增长难逆
→
建设性出口：跨品牌（先咖啡+美禄）共用的篮球生活场景 OS + 样板城 sell-out
```

### 交汇「假交汇」警告

| 假交汇 | 为何假 |
|--------|--------|
| 「行业 +1.3% 所以该赞助」 | β≠α；公司刚 −6.4% |
| 「有易建联所以已完成体育」 | 点≠面；咖啡仍缺场景 |
| 「Q2 +2% 所以预算松了」 | 品类仍负；基数效应 |
| 「外企都在砍中国」 | IR 仍单独讲中国稳定与模型 |

## 三层「认不认」预演

| 层级 | 可能的反应 | 我们的下一问 |
|------|------------|--------------|
| BU 营销 | 「可以先听听场景」 | 样板城与 KPI 愿不愿意共写？ |
| 市场 CEO | 「先证明不扰乱渠道」 | 是否接受零进货绑赠条款？ |
| AOA/财务 | 「中国预算很紧」 | 能否挂集团增长平台 / 营销肌重建叙事？ |

若三层都只回「把报价发邮箱」——本案未过需求门，停在培育，不硬推 D。

## 与我方（NBA China）匹配

| 匹配 | 理由 | 风险 |
|------|------|------|
| 需求场景（训练/观赛/少年） | 对齐 demand-led 与价值主张「可见度+难忘」 | 被当成卖曝光 |
| 美禄已有易建联 | 降低「体育是不是我们的」教育成本 | 客户觉「有联了够了」 |
| 多品牌分层 | 像 NIO 三品牌逻辑的快消版 | 决策链跨 BU 慢 |
| 避开运动饮料主叙事 | 降与佳得乐冲突 | 合作故事变窄 |
| 样板城可熔断 | 对齐校正后文化 | 客户只想全国包 |

## 不交汇（刻意不做）

- 用奥运 TOP 级预算逻辑逼单  
- 以渠道压货传闻羞辱客户  
- 全球 101 粉丝数  
- 挑战佳得乐官方饮料定位  
- 把营养线违规功能宣称塞进篮球故事
