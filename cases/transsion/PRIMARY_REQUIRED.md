## 为何需要 L0

外部 L2 能证明：利润腰斩与费用仍增、非洲份额仍强、TECNO 足球/代言资产、年报要中高端与跨市场复制。  
但 **2026 非足球试验预算、TECNO/Infinix 预算是否分池、经销商是否嫌赛事不带货、$200+ 是否内部 OKR**，不会出现在年报。

## 待验证假说

**假说**：客户需要的是服务 ASP/中高端的可熔断文化 OS，不是下一张赛事 Logo。  
**若真**：谈样板国 + 绑在售中高端 SKU + 熔断。  
**若假**（客户认为非洲杯+代言+数字营销已闭环，或只差降本）：discard 文化 OS；改谈产品/渠道诊断或结束。

## 销售 checklist（首面后 72h）

- [ ] 客户 business problem 原话  
- [ ] 见面人线：品牌 / 区域国家 / 财务 / 产品中高端 / 其他  
- [ ] 体育/内容：initiator / veto  
- [ ] 2026 **非足球、非代言**试验预算有无；上限数字  
- [ ] TECNO / Infinix / itel 预算是否分池  
- [ ] 样板国候选人；该国经销商对 2025 品牌活动评价  
- [ ] #1 顾虑：钱 / 足球已满 / 亚洲优先级 / H 股窗口 / 其他
