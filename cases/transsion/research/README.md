## 研究使用说明

本目录是水下冰山，不是会面逐字稿。它的职责是把传音的财务、产品、区域、组织、渠道、营销与体育资产放在同一证据框架内，帮助销售在首面只问最关键的三问。材料中的 A 源事实可进入事实区；C 源合作与媒体线索须保留来源等级；任何组织、预算、用户、ROI 与决策流程未知项均写【待核实】。

### 阅读路径

1. 先读 `01_IR_financial.md`，理解 2025 的核心约束不是单一营收下降，而是手机毛利、利润和现金流承压，同时研发与销售费用继续增加。  
2. 读 `03_partnership_history.md` 与 `11_marketing_sports_pr.md`，确认 TECNO 已有非洲杯、梦想球场和张艺兴，禁止以“缺体育”开场。  
3. 读 `10_product_audience_matrix.md`，把合作缩到一个品牌、一个国家、一个机型和一个价值点。  
4. 读 `06_power_meddic.md`，确认项目级 Pain、Metrics、预算、执行与否决角色尚未关闭。  
5. 读 `08_horizontal_vertical_full.md`，从三条候选张力中只选择一条进入首面。  
6. 最后读 `09_not_for_pitch.md`，删除容易翻车的数字、推断和话术。

## 证据纪律

| 内容 | 当前处理 |
|------|----------|
| 2025 年报财务、地区、产品、出货、市占、经销商与覆盖 | A 源，可引用并保留口径 |
| 非洲杯官方全球合作伙伴、梦想球场、张艺兴合作 | C 源品牌/体育公开事实，签约细节与 ROI 不推断 |
| NBA 体系合作 | 公开未见；只写“未见”，不写“没有”或“急需” |
| 分品牌收入、利润、预算、用户比例 | 【待核实】 |
| 未来三年收入、利润、市场与项目预测 | 不编 |
| 项目审批、预算 Owner、数据 Owner、经销商核销 | 【待核实】，必须靠 L0 关闭 |

所有百分比、金额、排名与数量都应回到对应文件的时间锚和来源级别。市占不等于收入或利润，销售费用不等于品牌预算，出货不等于 sell-out。

## 当前研究裁决

现有外部证据支持一次问题发现会，但不支持直接出售大型体育权益。允许推进的窄假说是：若客户确认某个品牌、国家和在售中高端机型存在现有足球资产未承担的文化任务，并能由经销商提供基线和结果数据，则可以设计有停止条件的小试验。

以下任一反证出现，应 PIVOT 或停止：

- 非洲杯已经成熟覆盖拟议任务；  
- 客户明确体育或文化预算关闭；  
- 无法指定品牌、国家、机型或产品价值点；  
- 只有曝光指标，无法获得任何近端经营证据；  
- 总部、国家、经销商和财务之间没有可执行 Owner；  
- 合作必须依赖未核实的受众、排他、价格或转化承诺。

## 会面前最小共识

销售团队内部必须统一：

- 不贬低非洲杯，不把篮球描述为足球替代；  
- 不用全球球迷数、CPM 或完整权益目录开场；  
- 不把利润下降归因于营销；  
- 不把印度位置归因于单一品牌问题；  
- 不承诺 ASP、销量或全球复制结果；  
- 只请求客户帮助关闭业务问题、目标单元和决策流程。

会面后七十二小时内，至少记录客户原话版业务问题、目标品牌与国家、机型与价值点、发起/预算/执行/数据/否决角色、可用基线、现有资产边界及下一次会议所需人员。若这些字段没有明显进展，机会仍停留在发现阶段。
