# 体育权益运营深拆：从合同附件到国家可调用资产

> 本页不是对比亚迪现有流程的事实描述，而是基于已公开合作边界提出的尽调框架与运营设计。凡涉及合同、预算、数据权限、内部审批和实际 KPI，均为【待核实】。已证合作事实回链 `03_partnership_history.md` 与 A 源。

## 一、先把“买到权益”拆成七种不同能力

体育合作官宣常把“全球伙伴、内容、活动、触达”写在同一段里，实际运营却至少是七张权利表。任何一张缺失，都可能使国家市场看到资产却用不了。

| 权利层 | 必须从合同确认什么 | 国家市场真正要做什么 | 常见误判 | 本案状态 |
|---|---|---|---|---|
| 身份 | partner title、地域、期限、品类、排他 | 在当地物料合法使用合作身份 | “全球”自动等于所有国家、所有品牌 | 国米三年与全球汽车伙伴已证；细边界待核 |
| 标识 | 队徽、赛事标、奖杯、球衣、场馆视觉 | 形成当地语言和车型版本 | 有 logo 就能任意联名 | 【待核实】 |
| 人物 | 球员、教练、名宿、青训、代表出镜范围 | 选择与品牌 Job 匹配的人物 | 俱乐部合作等于球员代言 | 【待核实】 |
| 内容 | 拍摄日、素材库、直播、幕后、剪辑与存续期 | 按国家重剪并长期复用 | 一次全球大片等于内容系统 | 【待核实】 |
| 场地 | 比赛日、训练场、球迷区、hospitality、门票 | 把体验和试驾嵌入真实触点 | 官方用车等于可在场馆卖车 | 【待核实】 |
| 产品 | 官方车队、特别版、展示、试驾、联合商品 | 把权益接到具体品牌/车型 | 一辆联名车能自然全球销售 | 国米约70辆车与海狮07特别版已证；销售边界待核 |
| 数据 | 报名、抽奖、会员、票务、内容互动、consent | 形成可跟进且合规的用户进度 | “触达球迷”自动获得球迷名单 | 【待核实】 |

**决策含义：** Rights API 不是技术名词，而是一份“什么可以做、谁能做、做到何时、留下什么”的可搜索合同翻译。若它只列素材而不列数据、品牌与国家，就仍是资产目录，不是运营协议。

## 二、国米三年合作：公开事实与必须补齐的合同问题

### 已证公开事实

2025-07-21，比亚迪与国际米兰建立三年战略伙伴关系，官方身份为全球汽车合作伙伴；比亚迪将向俱乐部提供约 70 辆新能源车，覆盖纯电与 Super DM 插混，并披露海狮 07 特别定制版及后续国际活动、内容与创新项目方向。[A1]

这足以证明：

1. 关系不是单场 campaign，而有赛季连续性；
2. 合作不只 logo，已进入车队使用与产品表达；
3. 官方文本明确留出内容、活动和创新项目空间；
4. 公开文本没有证明球迷数据、试驾归因、国家调用或完整排他边界。

### 合同尽调 36 问

#### A. 身份与排他

1. “全球汽车合作伙伴”覆盖哪些国家和地区？
2. 是否存在俱乐部已有区域汽车伙伴、经销商或租赁合作的 carve-out？
3. 排他是整车、乘用车、新能源车、充电、商用车还是更窄品类？
4. BYD 集团身份是否自动覆盖腾势、方程豹、仰望及王朝/海洋？
5. 子品牌出现时应使用何种 lock-up？
6. 合作期限按自然年、赛季还是签约周年计算？
7. 合同终止后素材、特别版和用户数据各自保留多久？

#### B. 人物与内容

8. 每赛季可用球员/教练/名宿的数量、时长与提前期？
9. 是否有伤病、转会、国家队征召导致的替换机制？
10. 球员肖像能否用于车型广告、经销商物料和效果投放？
11. 是否允许国家市场二次剪辑、配音、字幕和本地 CTA？
12. 原始素材由谁保管，是否可跨赛季复用？
13. 内容审核由俱乐部、球员代理、联赛与 BYD 哪些角色共同完成？
14. 是否允许工程师、车主、青训家庭成为共同作者？
15. 是否允许产品参数、辅助驾驶、充电等技术主张进入俱乐部内容？

#### C. 场地与比赛日

16. 主场比赛日可用哪些区域：外广场、hospitality、停车区、媒体区、训练基地？
17. 展车、静态体验、模拟器、试乘、试驾分别需要谁批准？
18. 是否能在非比赛日使用场地？
19. 每赛季门票与 hospitality 配额如何分配到国家和品牌？
20. 场地是否允许收集 consent、预约试驾或发放经销商 CTA？
21. 未成年人参与需哪些监护与影像授权？
22. 车辆充电、消防、保险和人流容量边界是什么？

#### D. 产品与商业化

23. 海狮 07 特别版是车队定制、展示车、限量销售还是全球可售版本？
24. 联名元素的设计、生产、认证、库存与售后由谁负责？
25. 经销商可否使用特别版引流，使用到何时？
26. 约 70 辆车的实际使用人是谁，能否形成真实使用内容？
27. 球员/工作人员使用车辆是否允许被称为“体验”，不得自动称“代言”？
28. 是否允许把车辆使用反馈汇总给产品团队？

#### E. 数据与测量

29. 俱乐部能提供的是匿名洞察、媒体受众、活动报名还是可联系会员？
30. 双方在 GDPR 下分别是 controller、joint controller 还是 processor？
31. 用户同意的用途是否包含 BYD 经销商联系、跨国转移和再营销？
32. 国家经销商如何取得线索且保留来源事件 ID？
33. 票务、内容、活动、试驾和订单能否在匿名/聚合层连接？
34. 是否允许城市或门店级对照实验？
35. 赛季复盘提供实际交付还是潜在媒体价值？
36. 哪些指标触发整改、缩减或终止？

上述问题未取得合同前，任何“全球球迷身份层”只能写为愿景，不能写成已可实施。

## 三、权益调用不是下素材：完整工单应有 16 个字段

一个国家市场申请调用权益时，至少提交：

| 字段 | 为什么必要 | 拒绝条件 |
|---|---|---|
| 国家/城市 | 确认地域与法规 | 合同不覆盖 |
| 主品牌/系列 | 避免五品牌同台 | 未指定唯一主品牌 |
| 车型与上市阶段 | 接到真实经营窗口 | 无供车、无价格、无试驾 |
| 本地 business problem | 防止为用权益而用 | 只写“提升声量” |
| 本地人群 | 明确谁有真实 Job | 只写“广大球迷” |
| 可用权益 ID | 合同先于创意 | 无权利依据 |
| 技术证据 | 只用已发布能力 | 参数无 A 源或越界 |
| 用户任务 | 从观看变为完成 | 危险、过长或不可复制 |
| CTA | 试驾/服务/hospitality | 只剩扫码抽奖 |
| 经销承接人 | 防止线索落空 | 无容量与责任人 |
| 数据角色与 consent | 合规前置 | 用途、保留期不清 |
| 事件 ID | 串联触点 | 系统不能记录 |
| 基线 | 允许比较 | 只有目标没有历史 |
| 对照 | 识别增量 | 无法设置且仍宣称因果 |
| 安全/法务签字 | 一票否决 | 未批准先上线 |
| Kill 指标 | 防止惯性续做 | 不接受停止条件 |

这张工单的价值不是加审批，而是把“好创意”提前变成“可执行、可验收、可停止”的小合同。

## 四、从总部到国家的 RACI，不清楚就不要建平台

以下是建议责任模型，非 BYD 现状：

| 任务 | 集团品牌 | 海外区域 | 品牌 GM | 国家公司 | 经销商 | 法务/数据/安全 | IP 方 |
|---|---|---|---|---|---|---|---|
| 定义全球母命题 | A/R | C | C | I | I | C | C |
| 解释合同权益 | A | I | I | C | I | R | R |
| 指定主品牌 Job | C | C | A/R | C | I | C | I |
| 选国家/车型窗口 | C | A | C | R | C | I | I |
| 设计本地任务 | C | C | C | A/R | R | C | C |
| 审安全与主张 | I | I | C | C | C | A/R | I |
| 采集 consent | I | C | I | A | R | R | C |
| 承接试驾 | I | I | C | A | R | C | I |
| 增量复盘 | A | R | C | R | C | C | C |
| 扩张/停止 | A | R | R | C | C | C | I |

R=执行，A=最终负责，C=会签，I=知会。若一项任务同时有多个 A，通常意味着停止权不清；若经销商只被 I，线索闭环大概率是纸面闭环。

## 五、不同体育资产不能用同一运营模板

### 1. 大赛型：欧洲杯、美洲杯

**强项：** 短期高峰、国家情绪、场馆与球迷区、大规模出行角色。  
**弱项：** 周期短、权利集中、赛后折旧快、不同国家情绪变化大。  
**合理 Job：** 让陌生品牌快速获得合法性，并把第一次体验导入本地经销。  
**必须留下：** 经批准可复用素材、国家任务模板、同意用户、门店能力与赛后复盘。  
**不该承诺：** 大赛曝光直接带来销量；官方用车等于赛事减碳。

### 2. 俱乐部型：国际米兰

**强项：** 三年节奏、主场触点、球员/名宿/青训叙事、持续内容。  
**弱项：** 核心影响力仍有地域浓度；球迷身份由俱乐部掌握；赛季成绩波动。  
**合理 Job：** 把单次内容改成连续用户进度，把车队真实使用改成技术见证。  
**必须留下：** 赛季路线、国家调用日志、品牌路由、重复参与与试驾质量。  
**不该承诺：** 俱乐部全球粉丝总量就是 BYD 可联系线索。

### 3. 国家联赛/国家队型：泰国足球

**强项：** 与本地制造、就业、经销和国家认同有更直接关系。  
**弱项：** 权益汇总官宣不足以证明合同细节；国家队与联赛权利可能分属不同主体。  
**合理 Job：** 把工厂、员工、家庭、球队和经销商连成当地共同作者网络。  
**必须留下：** 泰国团队定义的问题、本地语言资产、员工/社区参与、门店结果。  
**不该承诺：** 总部模板平移即可获得本地品牌属性。

### 4. 治理/hospitality 型：ANOC 香港

**强项：** 代表层级高，腾势作为指定用车有清晰品牌路由，服务可被标准化。  
**弱项：** 参与人群规模有限，不适合拿大众触达证明价值。  
**合理 Job：** 建立腾势国际事件礼宾与安全服务标准。  
**必须留下：** 车队调度、礼宾、反馈、服务培训和可复制 SOP。  
**不该承诺：** 一次大会自动成为大众品牌增长引擎。

### 5. 青年/技能型：滑板与轮滑

**强项：** 青年文化、技能进步、国家队精神与车型承接。  
**弱项：** 未成年人、伤害、影像授权、亚文化真实性要求高。  
**合理 Job：** 让品牌支持真实技能进度和安全参与，而非借青年符号。  
**必须留下：** 训练机会、教练网络、社区内容、参与者保护。  
**不该承诺：** “年轻人喜欢运动，所以会买车”。

## 六、赛季运营节奏：12 个月不是 12 次海报

### Phase 0：合同翻译与基线（赛季前 8–12 周）

- 建权益字段表与禁区；
- 只选一个业务问题；
- 取得上一赛季/普通活动基线；
- 确认品牌、国家、车型、库存与试驾容量；
- 完成数据影响评估与安全评审；
- 选择试点/对照城市。

**Gate 0：** 合同、经营承接、数据、安全任何一项不成立，停止。

### Phase 1：母任务与本地共同设计（赛季前 4–8 周）

- 总部定义技术真相与不可修改边界；
- 国家团队定义当地张力、语言与文化；
- 经销商把任务压到可承受时长；
- IP 方确认人物、场地和内容；
- 小样盲测用户能否正确复述技术价值。

**Gate 1：** 用户只记得“好玩/球星”，不记得品牌 Job，则重做或杀死。

### Phase 2：小流量试跑（2–4 周）

- 先用静态或模拟任务；
- 记录开始、完成、理解、consent、CTA、到店；
- 每天审安全、投诉、放弃原因与门店容量；
- 不用礼品掩盖低完成率。

**Gate 2：** 任务参与者的高质量到店不优于普通活动，停止扩量。

### Phase 3：赛季运营

- 国家按同一事件字典上报，不强求同一创意；
- 每月只新增一项变量，避免无法归因；
- 对高端品牌控制人数与邀请机制；
- 把母内容复用和当地原创分开计量；
- 记录每次权益调用成本与审批周期。

### Phase 4：复盘与资产结转

复盘不只问“多少曝光”，而问：

1. 哪些国家第二次主动调用？
2. 哪些品牌 Job 被用户正确复述？
3. 哪些经销商愿意自费/共投再开？
4. 哪些 consent 可继续服务，哪些必须删除？
5. 哪些内容、教练、场地、SOP 可跨赛季保留？
6. 与对照相比是否有增量？
7. 哪些模块应该永久停止？

## 七、权益经济账：先分成本，再谈 ROI

公开资料没有赞助费和激活预算，因此不填任何金额。经济账至少分六层：

| 成本层 | 典型项目 | 谁可能承担 | 必问 |
|---|---|---|---|
| 权益 | 合作费、续约、升级权利 | 集团/区域/品牌【待核】 | 是沉没成本还是本项目新增 |
| 内容 | 拍摄、球员、制作、本地化 | 集团+国家 | 母内容复用是否真的省成本 |
| 体验 | 场地、设备、车辆、教练、保险 | 国家/品牌 | 单次吞吐与安全成本 |
| 渠道 | 门店人员、试驾、礼品、加班 | 经销商/国家 | 谁补偿容量与机会成本 |
| 数据 | 表单、consent、事件 ID、分析 | 集团/国家 | 是否要新系统，还是先手工跑 |
| 治理 | 法务、审批、培训、复盘 | 各方 | 协议是否降低还是增加周期 |

允许计算的结果分三档：

- **效率结果：** 单个母资产被多少国家调用、每次本地化成本、审批周期；
- **行为结果：** 技术理解、有效同意、试驾预约与到店；
- **经营结果：** 对照 uplift、增量订单、每增量订单成本。

若无法建立对照，只能报告相关行为，不得把订单变化归因给体育。

## 八、最小可行版本：先用文件和事件 ID，不先造软件

MVP 只需要：

1. 一份人工校核的权益矩阵；
2. 五张品牌 Job 卡；
3. 一张国家激活工单；
4. 一套任务安全协议；
5. 一个统一事件 ID 规则；
6. 一页门店承接清单；
7. 一张周度增量复盘表；
8. 明确的停止人和停止条件。

如果两国试点证明国家愿意重复调用、数据可比较、门店结果更好，再决定是否产品化。否则“全球协议”会变成 another dashboard。

## 九、首面可直接拿来核实的八句话

1. “我们不假设你们没有权益管理系统，能否看一份已结束赛季从合同到国家落地的真实工单？”
2. “全球汽车伙伴这几个字，对腾势、方程豹、仰望是否同样可用？”
3. “哪类国家团队最常说‘这个全球权益跟我的销量没关系’？”
4. “国米的球迷数据，哪些只能匿名看，哪些可以在本地重新取得同意？”
5. “约 70 辆车留下的是车队服务证据，还是已经进入用户转化？”
6. “经销商调用一次俱乐部权益，要等几层批准？”
7. “如果协议让上线变慢，谁有权把它杀掉？”
8. “续约时，财务最信哪一个指标，最不信哪一个？”

## 十、结论

> 资产多不是问题，不能被准确调用才是问题；但公开资料不能证明比亚迪存在这个问题。真正可卖的不是一套宏大平台，而是一次合同可行、品牌清楚、国家愿意、门店接得住、数据说得明、未达就停的权益运营试验。
