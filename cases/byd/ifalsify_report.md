# ifalsify_report · 比亚迪

**Date:** 2026-08-26  
**Mode:** 反方优先 · 默认无 SURVIVES  
**Overall:** **CONDITIONAL / PIVOT-ready**

## 可证伪 Hypothesis

> 比亚迪已把车、工厂和体育权益带到全球，但现有全球体育关系在“合同权益→品牌路由→国家调用→经销承接→经营归因”之间可能仍需重复搭建；若这一缺口真实，一套轻量全球信任协议加一个五分钟技术证明试点，会比再买曝光更能提高现有权益复用与高质量试驾。公开资料只证明资产与经营张力，**不证明内部流程缺口**。

## Disconfirm Hunt

### F1 · 内部早已有成熟全球运营层
- **Attacks:** 官网不披露不等于没有系统。
- **Evidence:** BYD 已有多国运营、全球权益和成熟组织；内部 toolkit/CRM/复盘【待核实】。
- **Strength:** **Severe**
- **Experiment:** 看一份已结束赛季从合同到国家复盘的真实工单。若调用、路由、经销与归因成熟，A 概念 **KILL**。

### F2 · 当前前三经营问题不是品牌/体验
- **Attacks:** 2026 压力可能来自产品、价格、库存、服务、金融或贸易。
- **Evidence:** 财报只证明压力，不证明原因。
- **Strength:** **Fatal**
- **Experiment:** 海外经营负责人排序前三问题；品牌信任/技术理解/试驾质量不在其中，则不争主预算。

### F3 · 球迷数据不可合法获得
- **Attacks:** 合同、GDPR、国家系统不允许用户身份层。
- **Strength:** **Severe**
- **Experiment:** 法务确认数据角色、用途与跨境；用户级不可行则降为门店级增量，不能卖全球 CRM。

### F4 · 经销商不愿承接
- **Attacks:** 低质扫码、人员和试驾容量让门店承担成本。
- **Evidence:** 2025 经销收入占 54.33%，经销是经营主体，不是末端工具。[A1]
- **Strength:** **Severe**
- **Experiment:** 访谈试点门店，由其定义任务时长、容量、激励与 Kill；无 champion 则 B **KILL**。

### F5 · 五分钟把技术做浅
- **Attacks:** 用户只记得好玩/球星，误解闪充或辅助驾驶。
- **Strength:** **Severe**
- **Experiment:** 盲测价值、条件、边界和品牌；误导高于普通展示即停。

### F6 · 效果广告更便宜
- **Attacks:** 同预算效果投放带来更多可追踪试驾。
- **Strength:** **High**
- **Experiment:** 同城同期比较到店质量、品牌理解和长期资产；三项均无优势则回广告。

### F7 · 总部协议制造新官僚
- **Attacks:** 权益矩阵、工单和 dashboard 让国家更慢。
- **Strength:** **High**
- **Experiment:** MVP 不开发软件；比较 brief→上线周期、返工、第二国复用。更慢且无改善则 A **KILL**。

### F8 · 多品牌路由只是已有 brand book
- **Attacks:** Brand Router 可能只是换名。
- **Strength:** **High**
- **Experiment:** 抽一个真实激活，看是否已连合同、国家、车型、CTA、对照和停止；已完整则不单卖。

### F9 · 现有权益不允许任务化
- **Attacks:** 人物、场地、数据、商标、抽奖和试驾受限。
- **Strength:** **Severe**
- **Experiment:** Rights API 由合同生成；合同不可调用的模块删除，不让创意反推权利。

### F10 · 安全/数据风险吞噬收益
- **Attacks:** 驾驶、充电、未成年人或隐私事故会放大。
- **Strength:** **Fatal**
- **Experiment:** 静态/模拟优先；产品安全、法务、保险一票否决。

### F11 · 高端品牌不适合大众联赛
- **Attacks:** 腾势/仰望被人流与集章降格。
- **Strength:** **High**
- **Experiment:** 腾势用 hospitality，仰望邀请制见证；若仍以人流验收则移出。

### F12 · IP 方不愿把球迷变线索
- **Attacks:** 任务化伤害球迷关系。
- **Strength:** **High**
- **Experiment:** 基础体验不强迫 consent；IP 方共同设计。无法兼容则停。

## Overall Recommendation

1. **允许内部 grill 与 L0 会面。**
2. 只谈“验证现有权益是否值得安装可调用、可验收结构”，不宣称缺口已证实。
3. 只从一个 Economic Buyer、一个 IP、一个品牌、一个国家、一个任务开始。
4. 顶栏必须印 **CONDITIONAL**。
5. **禁用话术：** 缺曝光、缺年轻化、不会做体育、合作必带销量、我们统一全球 CRM。

**Confidence:** Medium-Low  
**升级条件:** 关闭合同、KPI、流程、经销、数据、预算、对照与 Kill。
