# Product Vision Flow（/pitchmachine product mode）

> iPod 路径：**不是零情报**，是 **JTBD + observation**，不是 IR 知彼。  
> 与 account mode 共用 gate 纪律，不共用 research/ 目录结构。

---

## 何时触发 product mode

- 新品类 / 新 bundle / 「客户还想不到要买」
- Product OS 登记新 Product Card 前的 narrative 试跑
- 找 early adopter，而非打单一账户

---

## 产出（替代 research/ 冰山）

| 文件 | 内容 |
|------|------|
| `job_map.md` | For [who] · when [circumstance] · want [progress] · but [compromise] |
| `early_adopter.md` | 识货买家画像；谁有预算且痛够深 |
| `03_tensions.md` | **T5 品类张力**：旧方案结构性失败，非某 CEO 矛盾 |
| `B_knife.md` 或 validation | Big idea 60s + why now 三力 + 1 ask（试点/共创） |
| `D_product_skeleton.md` | **主产出** — Component Registry → Bundle 草案 |

**不做**：全量 MEDDIC、竞品 IR 精读（除非 early adopter 锚定在具体行业）。

---

## 信源（product 专用）

| 可用 | 不可用进刀 |
|------|------------|
| Switch interview 摘要（L0） | 单账户 CEO 叙事当 universal truth |
| 行为：购买/使用/ workaround | L3「行业趋势」空讲 |
| 101 / 组件能力（internal） | 未核实 SKU |
| 销售表单 B「ideal 客户」 | |

---

## product_gate（8/10）

- [ ] job_map 有 struggling moment（非 feature 列表）
- [ ] early_adopter 可识别且可接触
- [ ] why now 有三力，非 change blindness
- [ ] 与 Product Card 模板字段对齐
- [ ] 无 L4 编造 market size
- [ ] 若打具体行业账户，须声明「转 account 模式重跑」
- [ ] D_skeleton 有试点边界与叫停条件
- [ ] 未混 account 式「蛇打七寸」人身攻击
