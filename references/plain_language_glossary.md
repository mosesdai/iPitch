# 术语通俗对照 · BD 可读性规则

> **问题**：交付物里的高浓缩术语（ifalsify / L0 / 人格资产 / 熔断…）BD 和外部协作方看不懂，最后 10–30% 要人工翻译。  
> **规则**：**给 BD / 外部的材料（一页纸、给协作方的包）默认用右列通俗说法**；内部研究文件可保留术语但首次出现要括注。

## 对照表

| 内部术语 | 通俗说法（对外默认用这个） | 一句话解释 |
|----------|---------------------------|------------|
| 冰山 / research/ | **完整背景研究** | 查得很深的底料，大部分不直接说给客户听 |
| 刀子 / B_knife / 刀刃 | **10 分钟会面话术稿** | 见面真正要讲的极短版本 |
| A_dossier / 水线 | **研究精华摘要** | 深聊时用的中间层 |
| ifalsify / 反昏君 | **证伪核查 / 防自嗨核查** | 专门找「我们哪里可能想错了」的反方报告 |
| CONDITIONAL | **有条件推进** | 方向能谈，但先验证某个前提，否则收回 |
| KILL | **禁用话术 / 放弃该角度** | 这句话/这个角度不许对客户说 |
| PIVOT | **换个说法/换角度** | 原角度不成立，改方向再谈 |
| L0 / PRIMARY | **只能当面问客户的信息** | 公开渠道查不到，必须销售当面确认 |
| A 源 / B 源 / C 源 | **公司官方公告 / 权威转载 / 媒体报道** | 数据可靠度分级，官方公告最可信 |
| 叙事 vs 行为 | **他们说的 vs 实际发生的** | 官方口径和财报数据分开看，防被标题带偏 |
| 日历效应 / 时间锚 | **春节错位造成的数字波动 / 数据截止时间** | 同比大涨可能只是假期时间移动 |
| 人格资产 | **代言人资产** | 签下的代言人和品牌形象组合 |
| 张力 / T1 | **主打矛盾点** | 客户自己说的话和实际数据之间的矛盾，会面只打一个 |
| 熔断（试验） | **不达标随时叫停（的小试点）** | 先小规模试，效果不到线就停止，财务好批 |
| 样板城 | **试点城市** | 先选一两个城市做验证 |
| 钩子 | **开场切入点** | 进门第一句用客户最近的大动作破冰 |
| 场景 OS / 分层 OS | **一套分品牌可复制的打法** | 不是买一次曝光，而是各产品线各有一套可重复执行的方案 |
| 经销商政治 | **经销商利益关系** | 方案必须回答经销商赚什么，否则推不动 |
| 溯源表 / traceability | **数据来源清单** | 每个数字标出处，会面只说核实过的 |
| MEDDIC | **见客户前的六问清单** | ①他们用什么数字算账 ②谁管钱拍板 ③按什么标准挑供应商 ④内部流程怎么走 ⑤真正痛点是什么 ⑥有没有内线帮我们说话 |
| EB（Economic Buyer） | **管钱拍板人** | 不是接待你的人，是签字的那个人 |
| Champion | **内线** | 客户内部愿意替我们推的人 |
| SWOT / TOWS | **优劣机威四格 / 交叉出动作** | TOWS=把四格两两交叉，推出「该干什么」 |
| ROI | **投入产出比** | 花一块钱回来几块 |
| CAGR | **年均复合增长率** | 查不到就留空，不编 |
| IR | **上市公司官方披露** | 年报/公告，最可信来源 |
| urgency | **紧迫感** | 「假 urgency」=拿短期数字制造「不投就晚了」的假象，禁用 |
| iPod | **专属定制概念** | 为客户单独造的新玩法，不进标准货架 |
| 货架 | **标准产品菜单** | 可复用的标准合作包 |
| Gate / 门禁 | **质量检查关卡** | 研究不达标不许写话术、不许约会 |
| 宁空不编 | **查不到就留空** | 绝不为了好看编数字（尤其未来预测） |

## 使用规则

1. **对外材料**（ONE_PAGER、给协作方的整合包、handoff）：正文用通俗列；术语可括注一次，如「证伪核查（ifalsify）」。
2. **内部研究**（research/、gate、ifalsify_report）：可用术语，文件头保留一行指向本表。
3. **每个新案例的一页纸末尾**附 5–8 条本案用到的术语速查（不用全表）。
4. 新术语出现 → 先加进本表再上材料。
