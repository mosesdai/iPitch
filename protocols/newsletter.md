# Intel Newsletter 协议（每周情报周报）

> **目的**：把两类每周情报固化成可重复产出的周报，直接喂 pitch 管道。  
> **纪律**：沿用刀刃数据纪律 —— 每条带来源与日期；查不到写【待核实】；不编。  
> **输出语言**：BD 可读的通俗中文（见 `references/plain_language_glossary.md`）。

---

## 板块 1 · Sports Sponsorship Intel（体育赞助雷达）

**解决什么**：全行业最新体育赞助/合作交易，每周一次 → **识别新线索**（谁在买体育，谁可能买我们）。

### 采集范围
- 全行业品牌 × 体育资产（赛事、俱乐部、运动员、协会、场馆、转播、电竞含体育向）的**新官宣**合作
- 中国市场优先；出海中国品牌的海外体育合作也收

### 强制过滤（每期执行）
| 过滤 | 规则 | 维护文件 |
|------|------|----------|
| 已合作品牌 | 已与我方有合作的品牌 → **整条移除** | `references/newsletter/partners_exclude.md` |
| 非相关品类 | 运动装备/器材/运动服饰等自带体育属性的品类 → 移除 | 同上（品类段） |
| 旧闻 | 官宣超过 14 天的不进「本周新增」，可进「补录」 | — |

### 每条字段
`品牌 | 行业 | 体育资产（IP/对象）| 合作形态（代言/冠名/官方合作…）| 官宣日期 | 来源(链接+级别) | 线索价值（为什么可能买我们，一句话）| 建议动作（谁去跟进）`

## 板块 2 · Prospect Intel（管道客户动态）

**解决什么**：Pipeline 内每家目标客户，过去一周是否发生**重大事件** → 更新开场切入点与会面时机。

### 监控清单
`references/newsletter/watchlist.md`（起始：中策、极兔、库迪…；随 pipeline 增删）

### 事件类别（每家逐类扫）
| 类别 | 例子 |
|------|------|
| 产品 | 新品、涨价/降价、召回 |
| 战略 | 出海、开店/关店、并购、融资、IPO |
| 组织 | 高管变动、市场负责人换人、裁员/扩编 |
| 营销 | 新代言、大 campaign、体育/IP 动作、竞品签约 |
| 财务 | 财报、业绩预告、大额资本开支 |
| 舆情 | 危机、辟谣、热搜（标注是否已澄清） |

### 每家输出
- 有事件：`客户 | 事件 | 类别 | 日期 | 来源 | 对 pitch 的含义（切入点/时机变化）| 建议动作`
- 无事件：**明确写「本周无重大动态」**（防漏报≠没查）

## 产出与节奏

| 项 | 约定 |
|----|------|
| 频率 | 每周一期（建议周一出，覆盖上周） |
| 路径 | `newsletter/YYYY-Wxx.md`（可加 `html/` 镜像） |
| 模板 | `references/newsletter/weekly_template.md` |
| 执行 | 两个板块可并行开 subagent 采集，主编合并+过滤+复核来源 |
| 与 pitch 联动 | 板块 1 的高价值线索 → 建议 `/ipitch start [公司]`；板块 2 的大事件 → 更新对应案例的 `source_timeliness.md` 与开场切入点 |

## 质检（每期出刊前）

- [ ] 已合作品牌 / 非相关品类已剔除
- [ ] 每条有日期+来源链接；无来源的删
- [ ] watchlist 每家都有一行（含「无动态」）
- [ ] 用词通俗（BD 直接可读）
