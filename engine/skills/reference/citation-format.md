# 引用格式（程序回验）

每条要用的事实写成一对，单独成行：

```text
来源：https://…最终地址…
摘录：页面上的原话逐字
```

英文键也可：`URL:` / `excerpt:`。

## 规则

- 摘录必须是你抓到的页面正文里的子串；可用 `…` 拼接两段，每段都要能在页里找到。
- 写跟随跳转后的最终 URL，不要拼看起来像真的地址。
- 数字优先 PDF / 静态件；**当前引擎 Stage 1 尚不解析 PDF**——PDF 引用会 SKIP/导致护照红，请暂用 HTML 原文页或先把关键句抄进可抓 HTML。
- 编造 URL 或摘录会被 `citation_verify` 判红，比留空更严重。
