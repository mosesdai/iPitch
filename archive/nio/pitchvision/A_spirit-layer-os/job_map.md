# job_map · A · Spirit Layer OS

## When（circumstance）

- 车企进入 **品牌澄清期**：技术同质化，用户买的是 Spirit，不是参数。
- 同一集团下有 **2–3 个价格带/人群完全不同的子品牌**（蔚来 40万+ / 乐道家庭 / 萤火虫小车）。
- 采购与 agency 习惯仍是：**一个 IP、一套 KV、全品牌露出**。

## Want（progress）

CMO / 品牌一号位想：

> 「每个子品牌都有自己的 Spirit，但 **只维护一次顶级 IP 关系**；CFO 看到的不是曝光，是 **可审计的品牌资产**。」

## But（compromise · 今日 hire 的烂方案）

| 他们现在 hire 的 | 实际得到 |
|------------------|----------|
| 单次代言人（姚明） | ES9 **单点**，不复用到乐道/萤火虫 |
| 足球俱乐部合作（申花） | 乐道 **单点**，蔚来主品牌接不住 |
| 传统体育赞助包 | **CPM 逻辑** — 秦力洪/李斌 明确反感 |
| 内部活动（NIO Day、用户足球） | 强但 **不可外扩** 为标准件 |

## Struggling moment（会面可讲）

> 「姚明发布会前一天，内部问的不是『曝光多少』，而是 **『这算不算蔚来的 Spirit』** —— 你们已经用 **价值观** 买 IP 了。  
> 但采购系统仍只有 **『买一个包』** 这个按钮。Spirit Layer OS 是 **第二个按钮**。」

## New job to be done

**Install a Spirit routing layer** — 像 CDN 分发内容，分发 **Spirit 接口** 到三品牌，而非分发 logo。

## 不做什么

- 不卖「3.23 亿粉丝」
- 不替代姚明/申花 — **抽象成可复用层**
