# T5 · 品类张力 · A

> **旧品类结构性失败** — 不是「NIO 李斌说 A 做 B」。

## 旧品类定义

**「体育 IP = 媒体曝光 + logo 露出 + 赞助权益清单」**

- 采购按 **CPM / 曝光 / 粉丝量** 验收  
- 一个 KV 打 **全线**  
- 合同按 **年框 + 冠名** 锁定  

## 为何在 2026 结构性失败（multi-brand OEM）

| 失败模式 | 机制 |
|----------|------|
| **Spirit 稀释** | 乐道「轻松家庭」与蔚来「敢想有为」共用 **同一曝光叙事** → 用户认知打架 |
| **CFO 拒签** | 大额冠名 **不可归因 Spirit** → 曲玉频道过不了 |
| **单点 IP 陷阱** | 姚明只服务 ES9；申花只服务乐道 — **每多一个 IP 多一轮谈判** |
| **反用户企业** | 模板化权益包 ≠ **用户可参与资产**（NIO 飞轮相反） |

## 新品类对立面

**Spirit Layer OS** — IP 关系 **一次签、三层路由**；验收 **Spirit 一致性 + 用户参与 + 分品牌 KPI**，不是 CPM。

## 会面一句（T5）

「问题不是 **买不买 NBA**，是 **采购系统还只有『曝光包』这个品类** — 三品牌时代这个品类 **结构上就不work**。」

## 与 account T1 区别

| account T1 | pitchvision T5 |
|------------|----------------|
| NIO **这家** 乐道 vs Spirit | **整个行业** 多品牌 × 旧采购品类 |
| 用 5月数据作证据 | 用 **姚明+申花+行业惯例** 作证据 |
| 认不认 **分层方向** | 认不认 **新品类** |
