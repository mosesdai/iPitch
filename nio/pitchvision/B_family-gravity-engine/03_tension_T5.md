# T5 · B · Family Gravity Engine

## 旧品类

**「品牌 Campaign = 买曝光 + 声量 + 话题」**

- 验收：曝光、热搜、CPM  
- 与 **试驾/家庭线索** 归因弱  
- 乐道 **Spirit** 被蔚来 campaign **带跑**

## 结构性失败（2026 家庭 SUV）

| 模式 | 为何 fail |
|------|-----------|
| 效果广告 | 线索 ≠ **家庭决策单元** |
| 母品牌 campaign | Spirit **错位** |
| 一次性事件 | 无 **重力** — 周末结束即消散 |
| 纯冠名 | CFO **不可归因** |

## 新品类

**Family Gravity Engine** — 持续运行的 **家庭线下重力场**：

- 输入：Jr. NBA 城市赛、3X、球迷开放日、球童体验  
- 输出：**家庭试驾预约、门店到场、NPS 样本**  
- 验收：**线索成本、家庭占比、转化** — 不是曝光  

## T5 会面句

「乐道要的不是 **第 N 个 Campaign**，是 **第 N 个『全家来的星期六』** — 这是新品类，不是更大预算。」
