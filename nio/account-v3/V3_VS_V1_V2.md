## 6. v3 仍不如 v1 的地方（诚实）

- **v1 详版** 的 SPIN/论证 depth 仍适合 **二面 30min** — v3 刻意删掉，需用 `C_argument` + `A_dossier` 补
- **v3 PRIMARY open** — 完整版「试点金额」仍不能写，**v1 若假装能写反而是劣化**
- **HTML 精美度**：v1 mid platform HTML 更 polish；v3 HTML **functional** 为主

## 7. 结论

| 问题 | 答案 |
|------|------|
| v3 是否值得重跑？ | **是** — 5月数据 + timeliness + primary 诚实度 |
| v2 是否废弃？ | **否** — 作「无 iceberg 时间紧」fallback；应用 v3 的 T1 证据升级 |
| v1 是否废弃？ | **否** — 档案可作 research 素材；**勿**再直接当 10min 刀 |

**最大跃迁**：v2→v3 不是文案更好，而是 **信源栈 + 门禁 + 销售插槽** 制度化；刀刃短 30%，**杀伤点更集中在一组 A 源行为数据（5月乐道 12,029）**。
